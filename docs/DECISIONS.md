# 採用中の設計判断

更新: 2026-09-27。現在の実装・次の実装を拘束する判断だけを残す。判断の経緯と過去の版は[全文履歴](archive/DECISIONS_HISTORY_2026-09-27.md)。達成度は[STATUS](STATUS.md)で別に確認する。

1. **人物の自律と世界法則を最優先する。** 本人が届いた刺激、身体、文化、記憶、利害、約束から行動・拒否・待機を選ぶ。世界は環境変化と試行の可否・所要時間・結果を確定し、本人に代わって仕事や食事を決めない。`PersonalityModel` は本人の外側の境界で、rule/NN/LLM/人間は内部の実装方式。全方式に一つの採点式を強制しない。政治・外交・戦争の拡張は、この基盤より優先しない。
2. **持続と破綻を結果として測る。** 世界を進める側は共同体の食料・所得・価格・人口を目標値へ調整しない。本人の必要・利益・情報・行動が結びついて生活が続くか、どこで破綻するかを、90日と反事実で検証する。世界の状態と因果が保存・再開後も続くことと、各人の生活が安定することは別の条件。旧本編/A3の共同事業は回帰用の制度付き世界として維持し、新方式の達成と混同しない。
3. **場所と所有者を分ける。** 家・農場・市場は場所。商品、現金、食事の所有権は人物または明示された物体に属する。現物は包含木の`parentId`、権利は`ownerId`で表す。共同備蓄や世帯拠出は人物の委任・合意・慣行として明示する。
4. **商人は自分の資金と利益で取引する。** Sは市場の所有者だが、他人の持込品や財布まで所有しない。自己資金で仕入/運賃を負担し、売上から次の資金を作る。利益は新規通貨の発行ではない。価格・数量・期限は当事者の局所的な提示と承諾で決まり、全知の需給式では確定しない。
5. **農夫・運搬人・買主は実在の履行をする。** Fは作業前に単価と上限量を承諾し、採った実量だけを現地で渡して受け取る。CはSの預り金と食品を物理的に運ぶ。B1/B2は本人の財布で購入し、持ち帰って食べる。生活市場ではBが薪納品を提案し、Sが売場の燃料として受諾した場合だけ森で採り、物理納品後にSの自己資金から支払う。薪1を燃やした日に売場を開く。拒否・資金不足・未納品・腐敗を消さない。現在の市場実験はphase呼出しが残る。
6. **生活には身体と保存期限がある。** B1/B2の空腹、本人所有の備蓄、食事を同じ現物ロットで扱う。ベリーの現行fixtureは収穫日を含め3日間有効。F/C/Sの身体、食品別栄養、森林/農地の成長・技能・なわばりは次段。
7. **仕事と約束は因果を残す。** 提案、受諾、行動、納品、支払、失敗を別Eventとして追う。権限は約束だけで推定せず、権限証拠を検証してから物理操作へ渡す。世界の結果を本人が知るのは観察・伝達された後であり、中央から真実を直接注入しない。権限証拠の一般化と情報配送は未実装。
8. **互換性と再現性はモード別に明示する。** 旧本編/E1/A3と独立市場を排他的な実験として維持し、保存版の不一致を暗黙補完しない。取引のみの独立市場セーブは版2、薪仕事を伴う生活市場は版3。seedは保存するが現在乱数を使わず、外部Command再適用は未実装。
9. **既存の `sim` を目標の世界法則と同一視しない。** `packages/sim` は物体検証とともに中央の日次経済、役割順のphase、AI呼出しも含む実装上のディレクトリ。`physical.ts` も物体操作の一部で、身体・資源・仕事・情報・権限を統合した世界ではない。どの処理が本人の選択、情報配送・時計、世界法則、制度記録に属するかを明示して移す。
10. **設計案を完成機能と扱わない。** ルーティンのデータ駆動、汎用ActionProcess、イベントキュー、軍との共通物流は[基盤設計](README.md)にあるが、未実装部分は[STATUS](STATUS.md)に残す。新機能は小fixture、保存則、拒否/欠員対照から拡張する。
