# 採用中の設計判断

更新: 2026-10-02。現在の実装・次の実装を拘束する判断だけを残す。判断の経緯と過去の版は[全文履歴](archive/DECISIONS_HISTORY_2026-09-27.md)。達成度は[STATUS](STATUS.md)で別に確認する。

1. **人物の自律と世界法則を最優先する。** 本人が届いた刺激、身体、文化、記憶、利害、約束から行動・拒否・待機を選ぶ。世界は環境変化と試行の可否・所要時間・結果を確定し、本人に代わって仕事や食事を決めない。`PersonalityModel` は本人の外側の境界で、rule/NN/LLM/人間は内部の実装方式。全方式に一つの採点式を強制しない。政治・外交・戦争の拡張は、この基盤より優先しない。
2. **持続と破綻を結果として測る。** 世界を進める側は共同体の食料・所得・価格・人口を目標値へ調整しない。本人の必要・利益・情報・行動が結びついて生活が続くか、どこで破綻するかを、90日と反事実で検証する。世界の状態と因果が保存・再開後も続くことと、各人の生活が安定することは別の条件。旧本編/A3の共同事業は回帰用の制度付き世界として維持し、新方式の達成と混同しない。
3. **場所と所有者を分ける。** 家・農場・市場は場所。商品、現金、食事の所有権は人物または明示された物体に属する。現物は包含木の`parentId`、権利は`ownerId`で表す。共同備蓄や世帯拠出は人物の委任・合意・慣行として明示する。
4. **商人は自分の資金と利益で取引する。** Sは市場の所有者だが、他人の持込品や財布まで所有しない。自己資金で仕入/運賃を負担し、売上から次の資金を作る。利益は新規通貨の発行ではない。価格・数量・期限は当事者の局所的な提示と承諾で決まり、全知の需給式では確定しない。
5. **農夫・運搬人・買主は実在の履行をする。** Fは作業前に単価と上限量を承諾し、採った実量だけを現地で渡して受け取る。CはSの預り金と食品を物理的に運ぶ。B1/B2は本人の財布で購入し、持ち帰って食べる。生活市場ではBが薪納品を提案し、Sが売場の燃料として受諾した場合だけ森で採り、物理納品後にSの自己資金から支払う。薪1を燃やした日に売場を開く。拒否・資金不足・未納品・腐敗を消さない。現在の市場実験はphase呼出しが残る。
6. **生活には身体と保存期限がある。** B1/B2の空腹、本人所有の備蓄、食事を同じ現物ロットで扱う。旧 `living` のベリーfixtureは収穫日を含め3日間有効。版1以降の5人世界ではF/C/Sも食べる。版2の小fixtureで森林・農地の成長と穀物技能を確認し、土地経済fixtureではFの利用権を持つ4区画の穀物を90日の主食として検証した。生態版では野草に2単位/食の低栄養を設定した。他の食品の詳細な栄養や利用権の移転・共同利用は未実装。
7. **仕事と約束は因果を残す。** 提案、受諾、行動、納品、支払、失敗を別Eventとして追う。権限は約束だけで推定せず、権限証拠を検証してから物理操作へ渡す。世界の結果を本人が知るのは観察・伝達された後であり、中央から真実を直接注入しない。5人世界の情報配送と注文用証拠は実装済み。複数契約へ使える証拠形式は未実装。
8. **互換性と再現性はモード別に明示する。** 旧本編/E1/A3と独立市場を排他的な実験として維持し、保存版の不一致を暗黙補完しない。取引のみの独立市場セーブは版2、薪仕事を伴う生活市場は版3、5人世界のセーブは版2。5人世界では外部Commandと人格応答を記録して再実行する。rule人格はseedを保存するが現在乱数を使わない。
9. **既存の `sim` を目標の世界法則と同一視しない。** `packages/sim` は物体検証とともに中央の日次経済、役割順のphase、AI呼出しも含む実装上のディレクトリ。`physical.ts` も物体操作の一部で、身体・資源・仕事・情報・権限を統合した世界ではない。どの処理が本人の選択、情報配送・時計、世界法則、制度記録に属するかを明示して移す。
10. **設計案を完成機能と扱わない。** ルーティンのデータ駆動、汎用ActionProcess、イベントキュー、軍との共通物流は[基盤設計](README.md)にあるが、未実装部分は[STATUS](STATUS.md)に残す。新機能は小fixture、保存則、拒否/欠員対照から拡張する。
11. **起床と情報到達は個別に記録する。** `individual_work` は人物ごとの次回起床時刻と宛先付き刺激を持ち、未到達の提示IDによる承諾を世界側で拒否する。本人の主観更新と世界の履行Eventを別に保存し、現物引渡しと支払は当事者の別の試行で行う。この固定fixtureを市場全体の実装済み境界とはみなさない。

12. **90日正常系の候補は事前に実行可能性を検算する。** [段階0の数表](baseline/AUTONOMOUS_90_DAY_FEASIBILITY.md)は食料・薪・時間・通貨が循環し得る条件だけを示す。そこで置いた単価・交替・取引順をsimの職業別日課として実行せず、本人の判断と世界の作用から同じ結果が出るか別に受け入れる。

13. **5人の実行fixtureは算術fixtureと版を分ける。** [自律生活世界](baseline/AUTONOMOUS_VILLAGE_RESULT.md)は段階0から初期通貨と体力を変更したが、本人の起床と世界法則の境界は変えない。S/F/C/B全員が同じ判断インターフェース、身体、物体木を使う。委託金・現地現物・契約状態を照合した試行だけに物理操作権限を与える。通常90日の成功はこの版1条件に限って述べる。

14. **履歴は入力と判断応答まで残して再実行する。** 版2の[記録](baseline/VILLAGE_RECORDING_AND_LAND_V2.md)はEventに加えて現地観察、到達刺激、本人の記憶、人格の返答、外部Commandと初期条件を保存する。保存済み応答を同じ入力で再適用してGatewayを再実行し、別人格や別条件は独立に記録して比較する。記録の規則版が違えば暗黙に読み替えない。
15. **場所と育成を局所法則にする。** 矩形セルの道はA*で探索し、移動中のセル・辺の進捗と荷重費を保存する。植物は土地のパッチとして生育/採集を進め、作物の作業は本人の試行と作物別技能で決める。動物は餌となる植物と位置・空腹・成長を持つ。通常90日fixtureと畑作対照の達成度は別に報告する。
16. **土地経済の規則と産地を記録する。** 4区画の正常90日は版2の野生食料中心の記録とは別の規則版・fixtureで再実行する。作物の産地・収穫日をロットから売買・食事のEventまで引き継ぐ。道路競合、季節、果樹の開花、動物の出生・死亡は局所的な世界法則とし、人物の仕事を世界から指示しない。[実走と限界](baseline/LAND_ECONOMY_V3_RESULT.md)を参照する。
17. **描画と世界は同じセル地図を使う。** 1280×768ピクセルの表示は40×24セルを32ピクセルずつ描く。作物・補助植物は固有セルで育ち、作業者は対象セルへ移動してから試行する。岩・山・建物は矩形の通行不能セルで、A*はそこを迂回する。表示のためだけの移動や成長を作らず、[空間版の実走](baseline/SPATIAL_GRID_V4_RESULT.md)のEventを描く。地形別移動コストは次段で扱う。
18. **広さはCanvasの寸法でなく活動範囲で判定する。** 市場・家・森・畑・草原を分散させ、人物の通過セル、農作業のセル、動物の位置、障害物の迂回を[全域版の実走](baseline/WIDE_WORLD_V5_RESULT.md)で測る。1時間内の各移動セルもEventに残し、画面で順に再生する。
19. **野生植物の位置は本人の観察から知る。** 食用植物の局所探索では技能が観察半径を決め、本人は見えた熟した植物だけを選ぶ。採集は対象セルへの実際の往復経路と現地の在庫減少を伴い、食料ロットの産地を残す。[局所探索の実走](baseline/PLANT_EXPLORATION_RESULT.md)を参照。遠方の未知植物や薪の固定資源は後続で扱う。
20. **採集可能量は株と時間から決める。** [生態版の実走](baseline/ECOLOGICAL_LAND_V6_RESULT.md)ではベリーを4セルの株へ分け、野草・果樹・草・穀物も収穫後の再生時間を持つ。穀物の休止期間は土地の物理的な使用制約として置き、輪作や土壌への人間の判断とは混同しない。旧記録は別規則版で維持し、新版の経路は幾何費用のA*を使う。

21. **当面の農作業は所有農夫だけが行う。** ユーザー指定により雇用を導入せず、[所有畑版](baseline/OWNED_FARMS_V8_RESULT.md)ではF/B1/B2が別々の4区画を所有する。受付・完了時に所有者を検査し、自己所有の区画を本人の技能と現地観察から耕作・播種・収穫する。穀物は当面腐敗せず、野生食品の保存期限は残す。薪は停止を継続する。3農夫の自給成立とS/Cを含む市場の持続は分けて検証し、雇用を前提としない取引循環を次に設計する。

22. **野生食品は現金なしの自給と実在する余剰売買に使う。** [直接採集版](baseline/WILD_FOOD_MARKET_V9_RESULT.md)では全員が観察した野草・ベリーを現地へ往復して採り、直接食べられる。余剰提示だけで売上や所有移転を作らず、現地の買い手が購入すると現物と代金を同時に移す。資金不足・再生待ち・競合・売れ残りを消さない。採集を含む例の食事確認と、穀物・パンの加工経済の持続性は分ける。
23. **整合する穀物・パン経済の後に技能と職選択を加える。** ユーザー指定により固定職での持続を先の必須条件にしない。[計画](baseline/FOOD_ECONOMY_SKILLS_PLAN.md)に従い、現物・加工・所有・売買の整合、経験による技能獲得、本人の職選択の順に実装し、需要に応じた切替で経済が持続するかを最初の持続性目標とする。その後に木こり等を追加する。

24. **採集を現地の移動と作業として進める。** [現地作業版](baseline/LOCAL_WORK_V10_RESULT.md)では1時間内の自動往復をやめ、通常移動で植物セルに到着し、数量に応じた時間と体力でその場で採集する。食事・休息もその場で行い、作業がない農夫を畑の文字セルへ戻さない。余剰の販売では市場へ行く。旧往復版は別規則として記録を維持する。

25. **穀物は保存原料、パンは期限付きの加工品とする。** ユーザー指定により穀物の直接摂食を禁止する。[v11](baseline/BREAD_STORAGE_V11_RESULT.md)では収穫した穀物を本人が家か市場の本人所有の穀物庫へ運び、保存してから加工する。穀物は腐敗せず、パンは製造日から3日で腐敗する。産地・収穫日・製造日を分け、原料の減少と加工品の増加を同じ物理操作で確定する。製粉・製パンは当面2時間の一工程とし、薪は要求しない。旧記録の直接穀物の食事を現在の仕様の達成として報告しない。

26. **生活行動は身体と環境の欲求から本人が選ぶ。** 帰宅しないこと自体を誤りとせず、昼夜の気温、場所の保温、活動疲労、睡眠不足と回復の差を世界法則として設ける。本人は感じる欲求と既知の場所、移動・待機の負担、備蓄、売れ行きから行動を選ぶ。「夜は必ず帰宅」「2食あれば必ず1食売る」という日課で望む見た目へ補正しない。短い休憩と睡眠を分け、屋外滞在が妥当な対照も検証する。具体的な境界・実装順・受入は[身体・環境と行動選択の計画](baseline/NEEDS_AND_ACTION_SELECTION_PLAN.md)に置く。これらの追加法則の初期版を[v12](baseline/ANTICIPATORY_NEEDS_V12_RESULT.md)で実装し、一般の避難場所や変化する天候は後続とする。

27. **強い経験を記憶し、不快が強まる前に予測して行動する。** 現在の身体信号だけでは対処が間に合わない。本人は強い快・不快を感じた状況、直前の行動、結果までの遅れと回復を記憶し、通常の経過も使って将来の結果と対処時間を見積もる。予測の不確かさを持ち、届いた実際の経過で更新する。初期知識・伝聞も出所付きの信念とし、学習のために被害を必須にしない。予防の成功を「予防しなくても安全」と読み替えず、未選択の行動の結果は仮説として残す。[経験記憶と予測の設計](baseline/NEEDS_AND_ACTION_SELECTION_PLAN.md)の初期版は[v12](baseline/ANTICIPATORY_NEEDS_V12_RESULT.md)で実装。感情は身体の変化を代理指標とし、予測を世界の正解と扱わない。

28. **状況別の小モデルを選び、予測の信頼と行動の価値を分ける。** ユーザー合意により、[複数モデルの設計](baseline/MODULAR_PREDICTION_AND_ACTION_PLAN.md)を次のrule人格の実装方針とする。観測条件と予測誤差で同じ対象を予測するモデルの寄与・係数を更新し、快・不快と費用で行動を評価する。不快を正確に予測するモデルを低く評価せず、その予測から危険な行動を避ける。異なる領域の予測を短い行動列に組み合わせ、事前の予測と実結果をID・時刻・条件で対応させる。一過性の外れと持続変化、実行と未選択、中断と完了を区別する。定義済みの有限モデルから始め、モデル構造の自動発見を達成したとは扱わない。v12は平均・ばらつきの学習まで。[v13](baseline/PREDICTION_LEDGER_V13_RESULT.md)で移動の予測と実結果の対応を追加し、複数モデルの競合と行動評価の学習は後続。

29. **農夫の穀物を市場の製パンと購入へつなぐ。** ユーザーの指摘により、[v14](baseline/FOOD_MARKET_V14_RESULT.md)では全員の自宅製パンを初期条件から外し、製パン技能はSだけに与え、市場を加工場所とする。農夫は穀物を売り、代金でパンを買う。買い手が現地にいて所有原料と代金を実際に移すまで売上を作らない。Sの穀物購入は同じ取引で市場の本人所有庫へ搬入する。粗い質量単位で通貨を無視できる重さ0とし、通貨の数量・所有の保存は維持する。旧版の質量・製パン規則は変更しない。野生食品の自食を残し、売れ残り・資金偏在と経済の停止を隠さない。固定職で持続することを先の必須条件にせず、技能獲得・需要による職選択は後続とする。

30. **携帯と家の保管を実物の所在として区別する。** [v15](baseline/HOME_STORAGE_V15_RESULT.md)で各自宅に本人所有の収納箱を設ける。現金・食品・種・薪は現地で本人が預け、取り出す。物品の部分移転、所有・容量・産地・腐敗期限を維持し、家の物品を遠隔で携帯として使わない。デバッグは実物の状態記録を表示し、人格の最後の観察や未来の在庫を現在の物理状態と混同しない。快不快のバーは現在の身体負担の目安で、独立感情や学習済みの行動価値を実装したとは扱わない。収納目安は初期ruleで、帰宅時刻の強制日課は追加しない。
