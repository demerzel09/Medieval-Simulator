# 採用中の設計判断

更新: 2026-09-27。現在の実装・次の実装を拘束する判断だけを残す。判断の経緯と過去の版は[全文履歴](archive/DECISIONS_HISTORY_2026-09-27.md)。達成度は[STATUS](STATUS.md)で別に確認する。

1. **世界と人格を分ける。** `PersonalityModel` は本人に届いた刺激、文化、状況、主観状態から認識・動機・判断・試行を組み立てる外側の境界。rule/NN/LLM/人間は内部の実装方式で、全方式に一つの採点式や予測器を強制しない。simだけが真実、時間、所有、資産、結果を確定する。現行コードは設計の一部のみ実装。
2. **安定は結果として測る。** simが共同体の経済を中央で調整して食料や所得を補わない。本人の必要・利益・情報・行動で仕事がつながり、90日続くかを反事実で検証する。旧本編/A3の共同事業は回帰用の制度付き世界として維持し、新方式の達成と混同しない。
3. **場所と所有者を分ける。** 家・農場・市場は場所。商品、現金、食事の所有権は人物または明示された物体に属する。現物は包含木の`parentId`、権利は`ownerId`で表す。共同備蓄や世帯拠出は人物の委任・合意・慣行として明示する。
4. **商人は自分の資金と利益で取引する。** Sは市場の所有者だが、他人の持込品や財布まで所有しない。自己資金で仕入/運賃を負担し、売上から次の資金を作る。利益は新規通貨の発行ではない。価格・数量・期限は当事者の局所的な提示と承諾で決まり、全知の需給式では確定しない。
5. **農夫・運搬人・買主は実在の履行をする。** Fは作業前に単価と上限量を承諾し、採った実量だけを現地で渡して受け取る。CはSの預り金と食品を物理的に運ぶ。B1/B2は本人の財布で購入し、持ち帰って食べる。拒否・資金不足・未納品・腐敗を消さない。現在の市場実験はphase呼出しが残る。
6. **生活には身体と保存期限がある。** B1/B2の空腹、本人所有の備蓄、食事を同じ現物ロットで扱う。ベリーの現行fixtureは収穫日を含め3日間有効。F/C/Sの身体、食品別栄養、森林/農地の成長・技能・なわばりは次段。
7. **仕事と約束は因果を残す。** 提案、受諾、行動、納品、支払、失敗を別Eventとして追う。権限は約束だけで推定せず、権限証拠を検証してから物理操作へ渡す。後者の一般化は未実装。
8. **互換性と再現性はモード別に明示する。** 旧本編/E1/A3と独立市場を排他的な実験として維持し、保存版の不一致を暗黙補完しない。独立市場のセーブは版2。seedは保存するが現在乱数を使わず、外部Command再適用は未実装。
9. **設計案を完成機能と扱わない。** ルーティンのデータ駆動、汎用ActionProcess、イベントキュー、軍との共通物流は[基盤設計](README.md)にあるが、未実装部分は[STATUS](STATUS.md)に残す。新機能は小fixture、保存則、拒否/欠員対照から拡張する。
