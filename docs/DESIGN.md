# 自律する人物と世界 — 現行設計の基準

更新: 2026-10-02。これは現在の開発方針と実装境界の短い正本。初版の詳細な企画・受入条件は[原本](foundations/ORIGINAL_GAME_DESIGN.md)に保存した。原本にある将来機能を実装済みと解釈しない。達成値は[STATUS](STATUS.md)、採用中の判断は[DECISIONS](DECISIONS.md)を見る。

## 目的

**最優先は、人物が本人に届いた情報、身体の必要、記憶、文化、利害、他者との関係から自分で行動を選び、その作用と世界の制約から生活・仕事・交換・協力や対立が生じる、持続して進行できる世界を作ること。** 個人の生活も社会も存続を保証しない。資源不足、誤認、拒否、破産、欠食、死や制度の破綻も、行動と世界法則から生じた結果として残す。「持続的」とは中央が全員を救済して安定させることではなく、世界の状態と因果が破綻せず次の判断へ進み、条件が整えば生活が続くことをいう。

世界を進める側は、環境の変化と、人物が試みた作用の可否・所要時間・結果だけを確定する。中央の経済運営者として仕事を割り当てたり、全員の所得・食料・価格を目標値へ補正したりしない。政治・外交・戦争は、この人物と世界の上に後で成立させる対象であり、当面の開発優先度を下げる。現行の「峠と収穫」は1,000人・90日のローカルゲームで外交/軍事の勝敗を再現できるが、この最優先目標の達成証拠にはしない。M3の人間試遊も未実施。

当面は食べる、働く、物を運ぶ、売買する、約束するという生活の小さな連鎖で原理を検証する。固定配置の90日完走、資産保存、特定市場の利益だけでは自律性も持続性も証明できない。生活が成立する条件と破綻する条件を、地理・人員・情報・資源・権利・人格を変えた反事実で測る。

## 実行境界

1. **人物の判断。** 世界の真実と本人の認識を分ける。本人は届いた刺激、身体状態、文化、記憶、技能、目的、約束から、行動・受諾・拒否・待機を選ぶ。`packages/ai/personality.ts` の `PersonalityModel` が外側の境界で、rule/NN/LLM/人間は内部の実装方式。[人格設計](foundations/AGENT_INTERFACES_v2.md)と[自律行動契約](foundations/AUTONOMY_INTERFACE_CONTRACT.md)を参照。
2. **世界の正本と法則。** 世界はUI・ネットワーク・人格から独立し、環境の成長・劣化、身体の消耗、位置・移動・時間・容量・動力、物と通貨の保存を扱う。人物の試行に対し、実際の資源、権利、同意、契約証拠を検証して受理・拒否・進行・完了を確定する。世界は本人の代わりに仕事や食事を選ばず、望ましい人口・価格・所得へ調整しない。[物体・包含モデル](foundations/PHYSICAL_OBJECT_MODEL.md)を参照。
3. **情報と時間の接続。** 時計は環境の変化、移動や仕事の進捗、人物を起こす時刻と同時刻の競合順を管理する。観察、身体信号、会話、手紙、行為の結果は、届いた相手と時刻を持つ刺激として人物へ渡す。隠れた世界状態を本人の判断入力へ直接渡さない。この接続は行動を決めず、世界で起きたことを本人へ届ける。[自律行動契約](foundations/AUTONOMY_INTERFACE_CONTRACT.md)を参照。
4. **社会関係と制度。** 所有、利用権、約束、債務、組織の役割は、当事者の行動で作られ変わる世界の記録と制約。文化・慣行は人物の解釈と行動の方法に作用する。家・農場・市場や「世帯」が人格のないまま行動・分配しない。全住民と兵士は固有IDを持つ同じ人物で、現物・現金の所在と所有者を分ける。[慣行](foundations/SOCIAL_PRACTICES.md)、[ルーティン](foundations/DATA_DRIVEN_ROUTINES.md)を参照。

判断、試行、受理・拒否、仕事の進捗、納品、支払、失敗を因果Eventで追う。権利があっても現金や物は自動で移動しない。保存再開と同じ入力からの再現をモードごとに検証し、未接続のCommand再適用を実装済みとは呼ばない。

## 身体・環境から生活行動が生じる条件

帰宅・睡眠・食事を時刻で指示する日課ではなく、身体と環境が生む欲求から本人が選ぶ行動とする。世界は昼夜の気温、場所の遮蔽・保温、活動による消耗、覚醒による睡眠不足と睡眠の回復を扱う。本人は感じる寒さ・疲労・眠気、既知の利用可能な場所、移動負担と仕事の見込みから帰宅・近くでの休息・屋外睡眠・作業継続を選ぶ。条件によっては帰宅しないことも妥当であり、帰宅回数を自律性の受入指標にしない。

短い休憩と睡眠、原料備蓄と可食在庫、自食用の備蓄と販売する量を区別する。全知の最適行動や他人の需要を世界から渡さず、本人が知った売れ行きと身体状態を次の判断へ反映する。強い快・不快と日常の経過を本人の経験として記憶し、似た状況の将来と対処の所要時間を予測して、不快が強まる前に行動できるようにする。予測の確かさと実際の経過との差を更新し、世界の未来や未選択の行動の結果を正解として渡さない。数値と実装順・対照は[身体・環境と行動選択の計画](baseline/NEEDS_AND_ACTION_SELECTION_PLAN.md)にまとめる。[v12](baseline/ANTICIPATORY_NEEDS_V12_RESULT.md)でこれらの初期実装を追加した。気温周期と身体は抽象モデルであり、経験予測は少数の候補を扱うrule人格である。現行の食事成立と技能・職選択による経済の持続性を区別する。

## 「sim」という名前の範囲

この文書で目標とする**世界の法則・作用判定**は、既存の `packages/sim` ディレクトリ全体と同義ではない。現在の `sim` には物体検証に加え、本編の `dailyEconomy` による職業別生産・賃金・世帯移転、生活市場の `advanceMarketDay` によるS/C/F/Bのphase順序、AI呼出し、画面向け実験ランナーが混在する。これらは既存実験を動かす実装であって、中央運営をしない世界の完成形ではない。`physical.ts` も物体木・容量・所有の一部分で、身体、資源、仕事、情報到達、権限証拠を一つの世界法則としてまだ統合していない。

## 分離された実験と次の受入

本編M0〜M3は既存の90日ゲームとして維持する。E1/L1/A1〜A3は20人の現物流通・仕事・所得とA1の道具競合を調べる系列。`individual_life`は3人の採集生活、`individual_market`は個人所有の仕入・運送・販売、`living`は買主の家・備蓄・空腹・食事・薪仕事を加えた実験。実験間を統合済みとは扱わない。数値は[STATUS](STATUS.md)と[生活市場の実測](baseline/LIVING_MARKET_EXPERIMENT.md)にある。

現在の標準は[欲求・経験と予防行動v12](baseline/ANTICIPATORY_NEEDS_V12_RESULT.md)。穀物は直接食べられず、家・市場の穀物庫へ運んで保存し、パンへ加工する。全員90日各日1食を確認したが、備蓄に応じて生産・販売を控える結果で食品売買は0となり、加工品市場の持続性は未検証。次は[身体・環境と行動選択](baseline/NEEDS_AND_ACTION_SELECTION_PLAN.md)を整え、[穀物・パン、技能獲得と職選択の計画](baseline/FOOD_ECONOMY_SKILLS_PLAN.md)へ接続する。雇用・薪・木こりは後続とする。
