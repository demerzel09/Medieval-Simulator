# 群雄と約束 — 現行設計の基準

更新: 2026-09-27。これは現在の開発方針と実装境界の短い正本。初版の詳細な企画・受入条件は[原本](foundations/ORIGINAL_GAME_DESIGN.md)に保存した。原本にある将来機能を実装済みと解釈しない。達成値は[STATUS](STATUS.md)、採用中の判断は[DECISIONS](DECISIONS.md)を見る。

## 目的

文化、動機、約束、個人の利害、本人に届く情報、指揮と物理的制約から政治と戦争が生じる、遊べるストラテジーを作る。現行の「峠と収穫」は1,000人・90日のローカルゲームで、通常AIによる外交/軍事の勝利と無策の敗北を再現できる。M3の人間試遊は未実施。

次の開発目標は軍事機能の追加より先に、**人が自分の必要・利益・認識から働き、食べ、支払い、物を運んだ結果として続く経済**を作ること。固定配置の90日完走や資産保存だけでは自律的な社会を証明しない。買主が実際に食べ、働き、所得を得て再購入することを、地理・人員・供給の反事実を含めて測る。

## 変えない実行境界

- 世界の真実と人物の認識を分ける。人物は届いた情報、文化、記憶、身体状態から行動を提案する。`packages/ai/personality.ts` の `PersonalityModel` が人格の外側の境界で、rule/NN/LLM/人間は実装方式。[人格設計](foundations/AGENT_INTERFACES_v2.md)と[自律行動契約](foundations/AUTONOMY_INTERFACE_CONTRACT.md)を参照。
- simはUI・ネットワークから独立し、位置、時間、容量、所有権、権限、体力、通貨・物量保存を検証して結果を確定する。本人の行動を中央が代行しない。現行の市場実験には中央phaseが残り、ここは未達。
- 全住民と兵士は固有IDを持つ同じ人物。現物・現金は所在と所有者を別に記録し、人や荷車などの物体に収める。[物体・包含モデル](foundations/PHYSICAL_OBJECT_MODEL.md)を参照。家・農場・市場は場所で、場所自身が売買や給与支払をしない。
- 動機、仕事、対人約束、伝令、受諾、実行を因果Eventで追い、拒否・失敗・未払を結果として残す。seed・Command・保存状態からの再現はモードごとに区別し、小実験の未接続Command再適用を実装済みとは呼ばない。
- 社会的慣行は「訪問時に護衛を伴う」などの方法を与える。仕事の展開はデータ駆動を目指すが、世界の効果と保存則はsimが検証する。[慣行](foundations/SOCIAL_PRACTICES.md)、[ルーティン](foundations/DATA_DRIVEN_ROUTINES.md)を参照。

## 分離された実験と次の受入

本編M0〜M3は遊べる90日ゲーム。E1/L1/A1〜A3は20人の現物流通・仕事・所得とA1の道具競合を調べる系列。`individual_life`は3人の採集生活、`individual_market`は個人所有の仕入・運送・販売、`living`は買主の家・備蓄・空腹・食事を加えた実験。実験間を統合済みとは扱わない。数値は[STATUS](STATUS.md)と[生活市場の実測](baseline/LIVING_MARKET_EXPERIMENT.md)にある。

まずB1/B2が提供する実在の仕事または財、相手がそれを必要とする理由、人物間の合意、作業・納品・支払を同じ世界で成立させる。中央給付や帳尻合わせの賃金で空腹を消さない。続いてF/C/Sも同じ身体・食品ロットで食べ、仕事を各人の起床と情報到達から連結する。保存則、拒否、資金不足、食料不足、90日対照を検証する。複数食品、森と農地、技能、なわばり、故障・不作は[拡張順](baseline/FOOD_ECOLOGY_AND_MARKET_PLAN.md)を踏まえて段階化する。
