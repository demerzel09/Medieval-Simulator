# 薪停止の対照と森での待機の原因

更新: 2026-10-01。ユーザーの指摘を受け、保存済みv6の人物判断・移動・採集・取引Eventを確認した。

## 旧記録で森に集まる理由

B1/B2は自宅から森の拠点へ移動し、毎日合計5単位の薪を採集する。2単位を自分で燃やし、残りをF/S/Cへ各1単位販売する。資源は毎日5単位補充される固定の `wood_patch` であり、木の位置・伐採・斧・木こり技能・長期の再生はない。この採集と買主待ちが森への集合を作っていた。

Cは薪採集をせず、Fへの食料注文の伝達・引渡しのため森に待機する。Fは毎日畑の各区画まで往復するが、引渡し場所も森に固定されている。Sは市場にいる。例として30日目はFが3時に畑へ向かい、4〜8時に区画移動・耕作・播種・収穫、10時に森へ帰り、14時に引渡し。Cは7時に森へ行き、15時の買付まで待つ。B1は7時に薪採集を開始し、12時にFへ薪を売る。

## 停止の範囲

`woodEnabled: false` の別fixture `land-wood-paused` と規則版 `autonomous-village-wood-paused-v7` を追加した。旧fixture・旧記録は変更せず再実行可能。

- 薪資源の配置・初期在庫・補充を停止。
- 薪入札・採集・販売・燃焼を世界の受付で拒否。rule人格もこれらを提案しない。
- 燃料要求（coldの初期値と日次増加）を停止。燃料だけ使えず要求が増える状態を避ける。
- B1/B2は薪仕事を理由に森へ行かない。買える所持金があれば市場へ行く判断は残す。
- 食料生育・採集・栽培・運搬・販売・身体・動物の法則は継続する。食料の引渡し場所は依然森であり、移設は未実装。

## 実測と経済上の限界

初期通貨26・価格・役割を維持し、代替所得や補助金は追加していない。B1/B2の唯一の所得は薪販売だったため、停止後は小売価格6の食料を買えない。Sも薪の買付支出が消える一方、Bの食料購入収入が消え、農家・運搬人への支払資金が循環しない。

90日末の食事回数はS3、F10、C1、B1/B2各0。合計14食（食品16単位）、薪採集・使用・販売0、Bの移動0、通貨26保存。穀物収穫15・食品腐敗8。食料取引が続かず、Fの栽培も停止する。空腹は累積するが、この世界に人物の飢餓死亡はまだない。**これは薪停止による破綻を記録した対照で、90日の正常稼働ではない。**

記録はEvent 25,700・判断7,467件、最終状態ハッシュ `eeb2e330`。停止版の記録再実行で最終状態・Eventの一致を確認する。正常90日のv6も別記録として保存する。試行拒否4,094件の内訳は市場の注文不可2,132件、Fの移動体力不足1,962件で、失敗を記録から除いていない。

単体テスト30ファイル165件、記録画面のブラウザテスト2件、型検査を含む本番ビルドとコンテンツ検査に成功。受付での薪4操作の拒否、燃料要求0、Bの森への移動0、旧v6と停止v7の記録再実行を確認した。

```bash
npm run autonomy:village -- 90 --scenario land-wood-paused --daily
npm run autonomy:village -- replay fixtures/recordings/autonomous-village-wood-paused-90.v2.json.gz
npm run autonomy:village -- history fixtures/recordings/autonomous-village-wood-paused-90.v2.json.gz B1 /tmp/wood-paused-B1.json
```

## 次の設計

優先は薪以外の実作業と報酬契約により所得循環を回復すること。候補は農作業の手伝いで、土地利用権、技能、作業の完了証拠、雇用の本人判断、報酬の資金源を設計する必要がある。人数を消したり初期資金を大量に加えたりして正常90日を成立させない。

薪を再開する場合は、セルに根差した木、斧、木こり技能、伐採の体力・時間、多量の材と運搬、長期再生、少量の落枝、市場取引を別途設計する。今回は未実装。
