# 食事と個人備蓄を伴う市場の小実験

2026-09-27。前の `individual_market` は仕入れ・販売だけの対照として残す。`npm run autonomy:living -- 30` は同じS/F/Cの仕入れ契約と物体木に、B1/B2の空腹、家、個人所有の備蓄箱、食事と薪の仕事を加えた独立実験である。`/?individual=living` で1〜7日の日末と人物Eventを見られる。既存90日ゲームやA3とは別の世界である。

B1/B2はそれぞれ自分の家と備蓄箱を所有する。「世帯」という口座が通貨や食料を受け取ることはない。毎日の空腹増加は身体の状態変化であり、食べるか、市場へ行くか、何食買うか、持ち帰って保管するかは `PersonalityModel` への局所入力から本人が選ぶ。家では本人所有の備蓄から、賞味期限の近いロットを先に食べる。市場の実際の値段は到着してから観測し、出発判断では最後に知った値段を使う。物体の移動、通貨支払、食事、腐敗はsimで検証し、因果Eventを残す。位置移動は現在1時間単位の到着で、距離/荷重/体力の時間積算ではない。

薪はベリーと別の森の資源で、初期2、最大4、日次再生2。市場の売場は薪1を消費した日に限り開ける。B1/B2は既知の単価2で1本の納品を提案し、Sは売る食品・薪在庫・自己資金と前回の納品者を見て受諾する。受諾後にBが森へ移動し、薪を採って本人所有の袋に入れ、市場へ運んで引き渡す。Sは現物と引換えに自己所有の通貨2を本人の財布へ移す。提案、受諾、採集、納品、支払、燃焼は別Eventである。承諾拒否・作業拒否・引渡し拒否なら支払わず、納品前の薪はB所有のまま。薪は食品ではなく、Sは売場の営業に必要な物として買う。1日の採集・往復には判断と移動の時刻がかかるが、体力消費・荷重別時間は未実装。

標準fixtureはS現金10、B1/B2現金20ずつ、F/Cは0から始める。2日目のB1は1食を食べた後、翌日のための1食を本人所有の備蓄箱に残す。B2は初日の品切れにより空腹が残る。90日目は累計ベリー収穫10食、販売9食、食事9食、腐敗1食、薪の採集/燃焼各9本。薪の所得はB1が10、B2が8。S/F/C/B1/B2の現金は20/10/14/4/2で総量50は変わらない。B1/B2の空腹は85/86。食品の売上と薪の仕事は早期に止まり、**生活は安定していない**。Sの利益10だけで成功とは判定しない。

この縦断面で確認したのは、食料の所有/所在/鮮度とBの実物生産・支払が個人の移動・食事・備蓄の判断とつながり、所得があっても需要/供給/価格の結果として通貨不足が身体に及ぶことまで。F/C/Sはまだ空腹や食事を持たない。S/F/Cと薪仕事は中央の日次phaseから呼び出され、人物の起床・伝達だけから市場が進む構成ではない。家はB個人の場所で、複数人の同居、共同備蓄への拠出/許可、食料種類ごとの栄養差、栽培・探索・なわばり、直接販売は未実装。[次の拡張順](FOOD_ECOLOGY_AND_MARKET_PLAN.md)で扱う。

次の受入ではF/C/Sの食事を同じ物理ロットへ通し、所得・費用・需要・供給を変えた90日対照で安定と失敗を区別する。薪の購入が売上と同日にしか起きないため、需要が止まればBの仕事も止まる。この依存も対照で測る。

生活市場のセーブは薪の物体・資源状態を必須とする `schemaVersion: 3`。旧版2の生活市場セーブは暗黙補完せず拒否する。取引のみの市場は版2のまま残す。
