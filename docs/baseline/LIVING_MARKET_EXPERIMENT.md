# 食事と個人備蓄を伴う市場の小実験

2026-09-27。前の `individual_market` は仕入れ・販売だけの対照として残す。`npm run autonomy:living -- 30` は同じS/F/Cの仕入れ契約と物体木に、B1/B2の空腹、家、個人所有の備蓄箱、食事を加えた独立実験である。`/?individual=living` で1〜7日の日末と人物Eventを見られる。既存90日ゲームやA3とは別の世界である。

B1/B2はそれぞれ自分の家と備蓄箱を所有する。「世帯」という口座が通貨や食料を受け取ることはない。毎日の空腹増加は身体の状態変化であり、食べるか、市場へ行くか、何食買うか、持ち帰って保管するかは `PersonalityModel` への局所入力から本人が選ぶ。家では本人所有の備蓄から、賞味期限の近いロットを先に食べる。市場の実際の値段は到着してから観測し、出発判断では最後に知った値段を使う。物体の移動、通貨支払、食事、腐敗はsimで検証し、因果Eventを残す。位置移動は現在1時間単位の到着で、距離/荷重/体力の時間積算ではない。

標準fixtureはS現金10、B1/B2現金20ずつ、F/Cは0から始める。2日目のB1は1食を食べた後、翌日のための1食を本人所有の備蓄箱に残す。B2は初日の品切れにより空腹が残る。90日目は累計収穫8食、販売数量7食、食事7食、腐敗1食。S/F/C/B1/B2の現金は28/8/12/0/2で、B1/B2の空腹は86/87。現金総量50は変わらず、買主の所得がないため、食料が森に残っていても買えず、生活経済は成立しない。Sの利益18だけを成功の指標にしてはいけない。

この縦断面で確認したのは、食料の所有/所在/鮮度が個人の移動・食事・備蓄の判断とつながり、通貨不足が身体に及ぶことまで。F/C/Sはまだ空腹や食事を持たず、B1/B2には仕事と収入がない。S/F/Cの仕事は中央のphase呼出しであり、人物の起床・伝達・受諾だけから市場が進む構成でもない。家はB個人の場所で、複数人の同居、共同備蓄への拠出/許可、食料種類ごとの栄養差、栽培・探索・なわばり、直接販売は未実装。[次の拡張順](FOOD_ECOLOGY_AND_MARKET_PLAN.md)で扱う。

次の受入では、B1/B2が提供できる実在の仕事または生産物を作り、その対価が人から本人の財布へ移るようにする。Sが買主へ賃金を戻すだけの帳尻合わせにはしない。全員の食事を同じ物理ロットへ通し、所得・費用・需要・供給を変えた90日対照で安定と失敗を区別する。
