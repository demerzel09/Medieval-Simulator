## 世界法則

- 野生ベリー20個を4つの別セルの株に5個ずつ置いた。Fは初日から3日目まで、取引用の4個を毎日別の株まで往復して採る。採集Eventは株IDと食品ロットの産地を持つ。採った株は残りが1個でも7日間は再採集できず、回復時に5個へ戻る。森の在庫表示は4株の合計で、株の増加Eventからのみ増える。
- 野草は8地点で、採集後4日間再生する。野草は2単位で1食、ベリー・果実・穀物は1単位で1食とした。Fは初めの2日に野草、3日目に果樹の実を採る。果樹は採集後3日間の再生と1日間の開花を経て実をつける。草は10地点で、動物に食べられた後1日で再生する。
- 畑は12セル。播種後6日で穀物5単位が熟す。収穫後は3日間 `fallow`（休止中）となり、耕作・播種Actionを受け付けない。開始時点で4区画に3日間育った穀物を置き、最初の播種が育つまでの食料をつなぐ。休止は連作障害そのもののモデルではなく、土地の回復待ちの簡略化。
- 新版の人物・動物のA*は直進10・斜行14の幾何距離と同じ形の推定値を使い、障害物を集合で照会する。角抜けを禁止し、通行止めでは現位置から再計算する。森から畑への経路は旧探索法の幾何費用238から226に短縮した。地形別移動コストはまだ設定していない。
- グリッドの作物は播種・成長・成熟・休止で色や高さを変える。野草・ベリーは実や葉が消え、低い株から再生する。果樹は再生中の暗い冠、開花中の桃色、成熟時の橙の実で区別する。セル選択と凡例にも段階を表示する。

## 正常90日と再実行

```bash
npm run autonomy:village -- 90 --scenario land-ecology --daily
npm run autonomy:village -- replay fixtures/recordings/autonomous-village-ecological-90.v2.json.gz
```

seed 240924で5人全員が90日毎日1食・薪1を確保し、拒否・作業失敗は0。450食に使った食品は452単位で、穀物435、ベリー12、野草4、果実1。野草2食に各2単位を使った。食品の収穫/消費は各452、薪の採集/使用は各450。末日のウサギは8匹、出生11・老齢死5。規則版v6の記録を再実行し、最終状態とEventハッシュが一致した。

F5「自律: 土地経済90日の生態デバッグ画面」で「旧記録：固定薪資源あり」を選択、または `/?village=land-economy&wood=legacy` は[新しい90日記録](../../fixtures/recordings/autonomous-village-ecological-90.v2.json.gz)を表示する。分単位の表示位置は1世界時間内に記録された通過セルを均等配置した目安で、simの判断と植物の生育は世界時間単位で進む。

## 残る範囲

野草や果樹を能動的に採る判断は最初の3日に限る。穀物の6日成長は旧72時間より長いが、実際の中世農業の暦を再現した期間ではなく、90日生活を試すために圧縮した周期。森から離れた未知植物の探索、土壌栄養と輪作の選択、作物ごとの栄養差、複数人の同じ株への採集競合、薪を木ごとの資源にすることは未実装。人の移動は記録されたセルの歩進捗であり、分表示は物理的な5分刻みのsimではない。
