# 5人の自律生活世界: 実行結果

更新: 2026-09-27。[計画](AUTONOMOUS_90_DAY_PLAN.md)の段階1〜4を、`autonomous_village` モードで実装した。以下は版1時点の測定。版2の経路・土地・履歴の追加後の数値は[版2記録](VILLAGE_RECORDING_AND_LAND_V2.md)と[STATUS](../STATUS.md)を参照。実行は `npm run autonomy:village -- 90`、日別の食事・採集・取引・拒否は `npm run autonomy:village -- 90 --daily`、因果Event全体は `--events` で再現できる。seedは240924。通常のrule人格は乱数を使わないため、このseedを変えても同じ結果になる。

## 境界と初期条件

同じ起床・宛先付き刺激配送を5人に用い、`PersonalityModel` が届いた通知、現地観察、身体、本人の記憶から一回の試行と次の起床時刻を返す。世界は試行の権利・位置・所有・容量・体力・契約証拠を検査し、移動・採集・荷役・休息の経過、資源再生、食品腐敗、空腹と寒さを進める。職業別の時計phase、日次給付、欠員の代行は置かない。S/F/Cの食事と薪使用もB1/B2と同じ物体・身体規則を使う。F/C/Sは自分の寒さのためBの薪を買うので、Sの売場と別の実需がある。

[段階0の算術fixture](../../fixtures/autonomous-90.ts)は物理的な待ち時間を含まない。実行用[fixture](../../fixtures/autonomous-village.ts)ではFの初期通貨を0→4、初期体力を8→16、上限を10→20とし、通知遅延1時間を明記した。S20/F4/C0/B1 0/B2 2の総通貨26を保存する。Fの4は初日の薪代の運転資金で、日々の通貨注入ではない。価格は人格の初期信念と本人の提示・承諾から決まり、世界に売値の固定処理はない。

## 通常90日の実測

単回実行は約6秒。全員が各日1食と薪1本を本人の試行で使用し、末日の空腹・寒さは全員0。食料は採集450・食事450・腐敗0、薪は採集450・燃焼450。両資源の残量は3、通貨は26で、末日の財布はS20/F4/C0/B1 0/B2 2。注文・農産物の購入・納品は各90件、食品販売と薪販売は各270件。日61〜90にも納品30件、食品販売90件、薪販売90件がある。F/C/Sの薪購入は各日継続した。全20,140 Eventには本人の判断、刺激の原因、現物移転と支払が残る。

通常実行でも9件の一時的な未遂を記録した。9・12・26日目に薪売りが現地の買主の状態変化に遭い、試行拒否6件、進行中の売却失敗3件となった。その後に本人が別の行動を選び、全員の毎日の食事と薪使用は成立した。失敗を消す補填はない。

## 対照と範囲

`tests/autonomous-village.test.ts` でCまたはFが待機を選び続けると納品は起こらず、B1欠員では本人の食事が不足する。Sの初期通貨0では注文が立たず、薪の再生0では寒さが残り、Fへの通知を24時間遅らせると初日の注文承諾が起こらない。Cの運搬上限を17にすると委託金と食品を同時に積めず引渡しが失敗する。未到達の注文IDを推測しても受諾を拒否し、重複刺激は一度だけ処理する。採集権外のBの食料採集と、契約された現物引渡し前の委託金支払も拒否する。Fの部分納品2に対してCの現物支払は2で、余りはFの所有として残る。同時刻の薪採集は予約で競合を解決する。道中の保存再開と同seed・同Commandで、状態とEventのハッシュが一致する。

これは版1の5人・単一地理・一つのrule人格と正常初期条件に対する受入である。別の人数、技能、季節、価格形成方式、乱数を使う人格やLLMの90日存続は検証していない。旧 `individual_*` と本編は独立モードとして維持する。
