# 栄養・活動疲労・荷重の不快と行程判断 v22

更新: 2026-10-03。[設計](ENERGY_EFFORT_AND_DELAYED_REWARD_DESIGN.md)の初版を実装した。提示整合だけのv21を対照として保存し、身体と判断を接続したv22を別の規則・記録にした。経済の持続、技能獲得・転職はまだ達成していない。

## 実装

| 項目 | 対応 |
|---|---|
| 提示と現物 | 播種する穀物ロットを明示する。有効な販売提示の穀物は播種に使わない。消費・保管・腐敗等で提示と現物が合わなくなると、原因Event付きで提示を取り消す |
| 栄養備蓄N | 実際に消費した可食物だけが吸収待ちに入る。2時間後に吸収し、生活・作業・荷物の支持・回復で消費する。休息で栄養を生成しない |
| 活動疲労F | 栄養備蓄と別の保存状態。作業で増え、休息・睡眠で回復する。栄養供給が乏しいと回復が制限される |
| 活動余力R | `最大26 × clamp(N/12, 0, 1) × (1−F)`。既存の開始・進行の身体制約へ接続する。kcalの残量とは呼ばない |
| 現在の感覚 | 栄養不足の感覚、活動疲労、荷重の不快、快、負担軽減を分ける。荷卸しは現在の支持負担をすぐ減らすが、使った栄養・疲労を戻さない |
| 睡眠 | v20の睡眠圧・実睡眠・昼夜リズムを継承する。眠気には独立したFを渡し、栄養不足による低Rを同じ疲労と扱わない |
| 行程比較 | 指定ロットから実際に積める範囲で穀物の積載1〜5単位を比較する。積載往路・有効提示の有限待機・食料購入の時間・売れない場合の荷物付き帰路を含める。現在の身体・食料・寒さ・眠気の余裕を確認する |
| 有限の我慢 | 食料代として有用な現金の見込みが負担を上回れば運ぶ。目的と期限を保持し、現在の不快や期限超過で作業を中断する。現金の増加自体は身体を回復しない |
| 中断と保管 | 1時間の作業区切りで再検討し、実際のセル移動・消耗を残す。自分の庫、家、または現在のセルの置き荷へ保存する。置き荷の所有権と容量も保存する。栄養不足で仕事ができなくても、その場の荷卸しや自宅の必要な睡眠は選べる |
| 経験 | 予測ID・開始時刻・本人に届いたProcessの結果で活動疲労の誤差を照合する。重量・不足の感覚・寒さの条件ごとに見込みを更新する。途中までの実労力は学べるが、完了所要時間と混ぜない |
| 市場の経験 | 自分の有効提示の成立と期限内未成立を別に記録する。無効化・避難の途中打切り・待機中を、無需要の確定結果にしない |

### 栄養単位と帳簿

実人体に校正していない仮の栄養単位を用いる。内部は整数1000刻み/単位、活動疲労は100万刻み/全量。小数表示からkcal・kg・mを推測しない。

| 係数 | 初版 |
|---|---|
| 初期備蓄 / 容量 | 60 / 96単位 |
| 十分な供給 / 食欲の閾値 | 12 / 48単位 |
| 生活維持 | 1単位/時間 |
| 追加作業 | 作業強度1につき0.7単位/時間 |
| 回復の追加要求 | 0.15単位/時間 |
| 活動疲労の追加 | 作業強度1につき4ポイント/時間 |
| 休息の疲労回復 | 最大7.6ポイント/時間 × 栄養供給率。睡眠はさらに環境の質を掛ける |
| 静止中の荷物支持による疲労 | 重量1につき0.32ポイント/時間。休憩中も持ち続ければ発生する |
| 静止して荷物を支える追加要求 | 重量1につき0.025単位/時間 |
| 食品1単位の供給 | パン36、ベリー24、果実30、野草12。野草は2単位を1食として消費する |
| 吸収待ち | 120分 |

栄養の帳簿を全人物で検証する。

```text
初期備蓄 + 累計吸収 = 現在備蓄 + 累計実消費 + 明示した吸収損失
累計摂取 = 累計吸収 + 吸収待ち
```

供給不足で満たせなかった要求は、実消費と分けて累積する。容量超過の吸収損失も帳簿に出す。食事の物品消費、貨幣26単位、穀物の播種・収穫・加工、腐敗の既存帳簿も検証する。食品生育・睡眠必要量・貨幣総量を緩めて成立させていない。

### 本人に渡す情報と初期の見込み

本人にNの実量、世界の生理係数、将来の植物状態、他人の財布を渡さない。本人の感覚・活動余力、携帯品・自分の保管品、現地の植物・提示、本人に届いた結果を使う。市場・森・果樹園・草原の座標は、食品の有無を含まない既知の地理とする。未知の食品状態は現地へ行って確認する。

活動疲労の初期見込み、行程の利益・費用の重み、遅延割引、現金の備え8、販売待機2時間は、このゲームの初期仮定である。研究の実測係数やOSSの既成パラメータではない。反射的な不快への対処を先にし、有限の作業目的がある場合だけ負担を保持する。汎用の行動列探索や生物学的な認知機構の完全再現とは扱わない。

身体予測、所要時間、販売成立の見込みを別に更新する。疲労の条件モデルは対応する実経過の平均を使い、2件以上の経験で初期見込みから切り替える。売れた現金と、その現金で買う食品の価値を二重に足さず、食料代として必要な分の見込みだけを利益側へ置く。実際の購入機会を保証するモデルはまだ持たない。

## 起動・記録・対照

F5の先頭は「自律: デバッグ画面（最新 v22）」。`/?village=land-economy` または `&wood=energy` で表示する。人物の身体欄にN・吸収待ち・実消費・損失、独立した活動疲労、荷重の不快、快と負担軽減を追加した。履歴に理由・目的期限・積載候補・予測誤差・販売待機の結果を表示する。置き荷は地図と所有物欄で確認できる。

旧v20は `&wood=sleep`、提示整合だけのv21は `&wood=integrity`、旧v19は `&wood=plan`。旧記録を変更せず、同じ保存schema 2と共有JSONの外包を使う。

```bash
npm run autonomy:village -- 90 --scenario land-energy-effort
npm run autonomy:village -- replay fixtures/recordings/autonomous-village-energy-effort-90.v2.json.gz
npm run autonomy:village -- 90 --scenario land-offer-integrity
npm run autonomy:village -- 90 --scenario land-energy-effort --effort-learning-off \
  --record fixtures/recordings/autonomous-village-energy-effort-learning-off-90.v2.json.gz
npm run autonomy:village -- replay fixtures/recordings/autonomous-village-energy-effort-learning-off-90.v2.json.gz
```

`--effort-learning-off` は新しい活動疲労・販売成立の見込みの更新を止める。既存の移動時間・気温・睡眠の学習は継続するので、全学習を止めた対照とは呼ばない。

段階対照は旧v20・提示整合v21・身体と行程判断を接続したv22・v22の更新なしを90日記録として保存した。身体単独の追加は小さい帳簿・回復テストで検証し、身体だけ追加した独立の90日記録は作成していない。v21→v22では身体と行動判断を一緒に変えているため、90日の差を身体だけ／判断だけの効果と分解しない。

## 検証と限界

身体の吸収・消費・損失・供給不足、独立した疲労と眠気、荷卸し、指定ロットの播種、提示取消、実際のセルでの移動中断、置き荷の所有権、吸収待ちの保存再開を確認する。判断を本人の保存入力から再計算し、所持品と身体表示を時刻内のEventから投影して時刻末の実状態と照合する。軽い案・成立見込み・報酬の必要度の対照、更新なしの対照、旧v20/v18の保存・再実行も確認する。

- 新しい身体・提示整合・中断・荷卸し・行程と保存再開：8/8。栄養不足時も荷卸し・必要睡眠を妨げず、自宅の床へ置いても屋外扱いにしない。複数ロットの合計を、1ロットから運べる量と混同しない。
- 旧v20の身体・本人・保存・90日再実行：20/20。旧v18と共有JSON：13/13。旧3記録の在庫表示と睡眠身体の最終確認：14/14（上の睡眠テストと重複するため合算しない）。全体の`npm test`は今回実行していない。
- v21・v22・v22の更新なし：記録した判断入力／応答から2160時間を再実行し、状態hash・Event hashが一致。新v22の5日対照では、本人の保存入力から全判断応答を再計算して一致し、保存再開と時刻内の在庫・身体表示も照合した。
- 対象ブラウザ：2/2。標準v22の栄養・疲労・快／不快・吸収待ちを実Eventと照合し、v21／旧v20へ切り替えられる。旧v20の15分の入眠・実睡眠・起床表示を継承。画面の画像も確認した。
- 型検査を含む本番ビルド、コンテンツ検査、変更した文書のローカルリンク、`launch.json`の構文・既存起動経路、差分検査が成功。

次は、枯渇に至る本人の食料行程を先に分析する。小さい収穫で植物全体を再生待ちにする現行規則、採集の量と往復、身体消費に応じた食事の確保、市場での食品取得機会を調べる。資源を増やして帳尻を合わせる変更や、睡眠条件の緩和で成立扱いにはしない。栄養需要と身体費用を含めた食料・加工・売買が矛盾なく回ってから、明示的な技能習得・仕事の切替を追加する。認知作業のkcal係数、万能な長期計画、薪・雇用は今回の範囲に含めない。
