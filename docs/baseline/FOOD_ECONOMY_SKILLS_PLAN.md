# 穀物・パン、技能獲得と職選択の順序

更新: 2026-10-02。ユーザー指定により、固定職で90日持続することを先の必須条件にしない。最初の持続性の目標は、技能獲得と本人の職選択を組み込んだ穀物・パンの経済とする。

0. **現在の採集・自食・市場売買を確立する**：在庫保存、所有者、支払い、株の再生待ち、現金なしの食事を確認する。売れ残りを売上にせず、腐敗・自食・売り手の移動後の提示から食品や現金を作らない。確認後に製パンへ進む。
1. **食品の現物と加工の整合**：所有農夫が自分の畑で穀物を生産する。穀物からパンを作る加工に原料・収量・作業時間・体力を設定し、材料の減少と製品の増加、産地と所有者を記録する。売買の現物・代金・在庫を合わせ、不足・腐敗・売れ残り・資金不足を結果として残す。穀物の保存は当面無期限。製粉工程を別にするかは実装前の設計対象。薪はまだ要求しない。
2. **技能獲得**：栽培・加工の実際の経験を記録し、技能に反映する。初期能力だけでなく、獲得過程と作業への効果を比較可能にする。
3. **本人の職選択と切替**：到達した提示・現地観察・保有技能・見込み収入から本人が仕事を選び直す。世界が需要を全知で渡したり人数を職へ配分したりしない。
4. **持続性の検証**：需要に応じた技能と職の選択で経済が持続するかを90日・対照・記録再実行で測る。全員の食事だけでなく、原料・加工品・在庫・取引・作業・報酬・技能・職の変化を確認する。野生食品の自給で加工経済の停止が隠れないよう、食事の産地と加工品の利用を分けて報告する。
5. **生産の追加**：上記が機能した後、木・斧・木こり技能・伐採・長期再生や他の生産を追加する。

野草・ベリー・果実は全員が直接採集して食べる生存手段として残し、余剰は市場へ提示できる。採集の在庫・再生・体力・移動は維持し、現金がないことだけを飢えの原因にしない。ただし資源が枯渇した場合まで生存を保証する機能にはしない。

現状は[野生食品と余剰市場v9](WILD_FOOD_MARKET_V9_RESULT.md)まで。製パン、経験による技能獲得、職の切替は未実装。所有農夫だけが農作業を行い、雇用・共同利用は当面導入しない。

現時点で、食品の生産・販売以外の新しい所得手段は足さない。お金の入手は既存通貨の移転であり、共同体全体の通貨を増やす処理とは分ける。パンを加えた段階で取引が続かなくても、不足や資金の偏りを記録する。追加の収入手段の対応は、その結果を見てから検討する。
