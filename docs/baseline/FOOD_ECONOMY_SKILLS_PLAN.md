# 穀物・パン、技能獲得と職選択の順序

更新: 2026-10-02。ユーザー指定により、固定職で90日持続することを先の必須条件にしない。最初の持続性の目標は、技能獲得と本人の職選択を組み込んだ穀物・パンの経済とする。

0. **現在の採集・自食・市場売買を確立する**：在庫保存、所有者、支払い、株の再生待ち、現金なしの食事を確認する。売れ残りを売上にせず、腐敗・自食・売り手の移動後の提示から食品や現金を作らない。確認後に製パンへ進む。
1. **食品の現物と加工の整合**：所有農夫が自分の畑で穀物を生産する。穀物からパンを作る加工に原料・収量・作業時間・体力を設定し、材料の減少と製品の増加、産地と所有者を記録する。売買の現物・代金・在庫を合わせ、不足・腐敗・売れ残り・資金不足を結果として残す。穀物の保存は当面無期限。v11では製粉・製パンを2時間の一工程にまとめ、原料1→パン1とする。パンは製造日から3日で腐敗し、穀物は直接食べられない。薪はまだ要求しない。
2. **欲求と合理性による行動判断の土台**：[身体・環境と行動選択の計画](NEEDS_AND_ACTION_SELECTION_PLAN.md)に従い、備蓄と売れ行きを判断に反映し、気温・睡眠不足・場所の回復効果を整える。帰宅・食事・販売を固定時刻に指示せず、本人の知識・欲求・強い快不快の経験から将来の結果と対処時間を予測し、予防行動や目的の継続・見直しを選ぶ。[状況別の小モデルの設計](MODULAR_PREDICTION_AND_ACTION_PLAN.md)のA〜Dに従い、予測と実結果の対応、モデル競合、快・不快による行動評価と短い連鎖、食品経済との統合を具体化する。食品経済の整合と対照へ接続した後、技能と職の選択へ進む。
3. **技能獲得**：栽培・加工の実際の経験を記録し、技能に反映する。初期能力だけでなく、獲得過程と作業への効果を比較可能にする。
4. **本人の職選択と切替**：到達した提示・現地観察・保有技能・見込み収入から本人が仕事を選び直す。世界が需要を全知で渡したり人数を職へ配分したりしない。
5. **持続性の検証**：需要に応じた技能と職の選択で経済が持続するかを90日・対照・記録再実行で測る。全員の食事だけでなく、原料・加工品・在庫・取引・作業・報酬・技能・職の変化を確認する。野生食品の自給で加工経済の停止が隠れないよう、食事の産地と加工品の利用を分けて報告する。
6. **生産の追加**：上記が機能した後、木・斧・木こり技能・伐採・長期再生や他の生産を追加する。

野草・ベリー・果実は全員が直接採集して食べる生存手段として残し、余剰は市場へ提示できる。採集の在庫・再生・体力・移動は維持し、現金がないことだけを飢えの原因にしない。ただし資源が枯渇した場合まで生存を保証する機能にはしない。

現状は[人物状態・自宅保管v15](HOME_STORAGE_V15_RESULT.md)まで。v14の穀物・パン市場を継承し、自宅での現金・物品の保管と実物状態の表示を追加した。植物セルで作業し、農夫が穀物を市場へ実際に運んで売り、初期製パン技能を持つSが購入原料を保存・加工する。全員各90食を確認したが、野生食品を含み初日の3人は翌日にずれた結果であり、原料・加工品の商業循環の持続性は未受入。身体・環境と経験予測、備蓄を含む判断の初期版と、移動の予測・実結果対応は食品経済に接続した。次は小モデルの競合・選択と市場の不足対照を拡張し、経験による技能獲得・職選択へ進む。所有農夫だけが農作業を行い、雇用・共同利用は当面導入しない。

現時点で、食品の生産・販売以外の新しい所得手段は足さない。お金の入手は既存通貨の移転であり、共同体全体の通貨を増やす処理とは分ける。パンを加えた段階で取引が続かなくても、不足や資金の偏りを記録する。追加の収入手段の対応は、その結果を見てから検討する。

判断の後続として[v13](PREDICTION_LEDGER_V13_RESULT.md)で移動の事前予測と実結果の対応を追加した。CLIは `land-predictions`。食品の法則と職・技能の位置づけは継承し、次は小モデルの競合・切替へ進む。

農夫の市場利用を修正したv14では、初期製パン技能をSだけに与え、市場で購入穀物を保存・加工・販売する。農夫は原料を売り、代金で可食パンを買う。野生食品の自食を残す。初期価格は穀物5単位2、パン1単位1。価格適応や技能獲得は未実装で、現金の偏在を観察した。全員の食事と現物・所有・支払いの整合を市場持続の達成と混同しない。次は小モデル競合・行動評価の設計を進めながら、需要・売れ行きに応じる生産量、技能獲得・職選択で持続性を検査する。

## 穀物と播種用在庫の見直し（検討中）

ユーザーは「穀物の種」という物品表示が製パン原料と紛らわしいことを指摘した。現行記録は播種用と収穫原料を別在庫として保持するため、表示は「播種用の穀物」と「穀物」で分ける。次の候補は物品を同じ穀物に統合し、本人が播種用を取り分ける方式。種の別生成をやめ、初期原料・播種消費・収穫量・加工消費の保存則を揃える。重量と数量単位、携帯容量、移動時の体力消費・速度も合わせて検討する。統合は未実装で、在庫の扱いを確認中。何もせず市場から帰ること自体を失敗条件にせず、売買目的・現地の提示・身体と予測による理由を検証する。
