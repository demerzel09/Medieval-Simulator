# 穀物保存・パン加工 v11

更新: 2026-10-02。ユーザー指定の「穀物は直接食べられず腐敗しない、パンは腐敗する」を適用した。旧v8〜v10の「穀物で各日食事できる」という結果は、直接摂食を許していた旧規則の結果であり、現在の仕様の成立根拠には使わない。

## 実装した規則

- 収穫した穀物は本人の袋に入り、通常の経路移動で本人の家か市場へ運ぶ。本人所有の穀物庫へ実際に移した後に加工する。各人物の家と市場に容量128の穀物庫を置き、場所と所有権を分ける。市場への保存だけでは販売・代金・所有移転は起きない。
- 穀物は直接食べられない。腐敗期限はなく、穀物庫内の在庫は保存・再実行でも維持する。
- 製粉と製パンを当面一つの2時間の作業にまとめる。毎時体力1を使い、完了時の一つの物理操作で穀物1を減らしパン1を本人の袋へ作る。自宅か市場の保存済み原料が必要。他人の原料や遠隔の穀物庫は使えない。
- パンは製造日から3日で腐敗する（日境界で判定）。穀物の収穫日ではなく製造日を起点にし、産地と収穫日の履歴は引き継ぐ。
- 野草・ベリー・果実は直接食べられる。野草は2単位/食。余剰市場、株別の再生待ち、所有畑、現地での作業は継続する。
- 人格は穀物の運搬・保存を優先し、食べられる食品が2食未満なら保存原料から製パンする。パンや野生食品を自食・提示できる。基礎加工能力は固定で、技能獲得・職選択・雇用・薪はまだ導入しない。

## 90日の実測

seed `240924`、`land-bread`、2160時間。

| 項目 | 結果 |
| --- | --- |
| 毎日の食事 | 5人とも90日各日1食、計450食 |
| 穀物の直接摂食 | 0 |
| パンの食事 | 269 |
| ベリー / 野草 / 果実の食事 | 98 / 80 / 3 |
| 穀物収穫 / 保存 | 510単位 / 102回の保存 |
| 製パン / 終了時の未加工穀物 | 275 / 235単位 |
| 終了時のパン | 6単位 |
| 余剰売買 | 6回 |
| 試行拒否 / 作業失敗 | 0 / 22（採集競合による植物不足） |
| 最終状態 / Eventハッシュ | `20d25206` / `1a1b77f0` |
| 判断 / Event数 | 5876 / 36216 |

この例では必要分を加工して食べるためパン腐敗は0。別のテストで、古い穀物から製造したパンが製造日基準で腐敗し、残った穀物が消えないことを確認する。食事成立は自宅加工と野生食品を含む結果であり、製パン職の収入や加工品市場の持続性は未検証。次は原料・パンの市場循環と不足の対照を確認し、その後に経験による技能獲得と本人の職選択を加える。

## 実行とデバッグ

```sh
npm run autonomy:village -- 90 --scenario land-bread --daily
npm run autonomy:village -- 90 --scenario land-bread --record fixtures/recordings/autonomous-village-bread-90.v2.json.gz
```

F5「自律: 土地経済90日の生態デバッグ画面」の標準表示はv11。家・市場に保存量を描き、セル選択で所有者別の穀物庫を確認できる。旧規則の記録は選択欄で比較でき、既存記録は変更していない。
