## 現行版2から変える初期条件

| 項目 | 版2の通常世界 | 土地経済の候補 |
|---|---:|---:|
| 穀物区画、初期種、Fの穀物技能 | 1、2、レベル1 | 4、4、レベル2 |
| 1区画の収量・成長 | 5食、播種から72時間 | 同じ |
| 耕作・播種・収穫 | 2・1・2時間 | 技能2の既存Gateway規則で1・1・1時間 |
| 野生ベリー初期量・容量・日次再生 | 8・8・5 | 20・20・0。最初の3日に各5食採り、5食を予備に残す |
| 初期体力・上限・8時間休息の回復 | 16・20・8 | 20・20・8 |
| 初期通貨 S/F/C/B1/B2 | 20/4/0/0/2、合計26 | 同じ |
| 食品期限、食品/薪価格、運賃、薪の再生 | 版2の正常fixture | 同じ |

畑は現行地図のfieldに4区画を置く候補とし、Fは森から畑への往復2時間を見込む。Cは従来どおり市場と森を往復し、Fが収穫4食を森へ運んで現地引渡しする想定。Fの袋は8質量、Cは食品4と現金を運ぶ。森の食品20食のうち3日で15食を採り、5食を有限の予備として残す。4日目以降は旧ベリーの日次再生だけで生活できない。

## 日別の作付けと収支

| 日 | 食料 | 畑の作業 | Fの作業・移動・引渡し | 休息込み | 野生食料残 |
|---|---|---|---:|---:|---:|
| 1〜3 | 野生ベリー各5食 | 毎日1区画を耕作・播種 | 10時間/日 | 18時間/日 | 日3末に5 |
| 4 | 穀物区画1から5食 | 区画4を播種、区画1を収穫 | 6時間 | 14時間 | 5 |
| 5〜90 | 穀物を毎日1区画から5食 | 前日収穫した区画を播種し、成熟区画を収穫 | 6時間/日 | 14時間/日 | 5 |

4区画を3日成長の間にずらして播き、4日目から毎日1区画を収穫する。90日の食料は野生15食＋穀物435食＝450食で、5人が各日1食を食べる勘定。日61〜90の150食はすべて穀物。野生5食は末日まで未採取の予備で、日次再生は0。種は初期4＋収穫から87−播種90＝末日1で、再播種を90日目にも続ける。薪は版2と同じ日5本の採集・消費で累計450本。食品は収穫当日に渡して食べる想定なので、期限3日による腐敗はこの計算では0。

Fの最大は作業・移動・引渡し10時間＋休息8時間＝18時間/日で6時間の時刻余地がある。体力は初期20から、仕事1時間で1消費、休息8時間で8回復する計算で、休息直前の最小が6。種を播いた後に野生食料を袋に入れ、収穫で得る種は再播種前にも保持するとして、袋の最大質量は8。初日は袋の余裕がないので作業順の検証が必要。Cは市場―森の往復2時間と食品納品1時間を続け、預り金・運賃・食品の荷重を既存の容量20内に保つ。Cの移動に必要な体力は1日4、納品に1で、8時間休息の回復内。商人と買主の食事・薪・支払は版2と同じ毎日の循環を仮定する。

通貨はSがCへ運賃10、Fへ食品4の代金を渡し、S/C/Fが薪代各4を払う。C/B1/B2が食品代各6をSへ払う。Bの薪3本/2本の交替を含む既存の循環では、90日間どの日も総通貨26で、末日のS/F/C/B1/B2は20/4/0/0/2。外部からの通貨給付はない。

## 不足と距離の対照

| 変更 | 計算上の最初の不足 |
|---|---|
| 区画を4→3 | 7日目に成熟穀物なし |
| 初期種を4→2 | 3日目の播種に種なし |
| 初期野生食料を20→10、再生0のまま | 3日目の立ち上がり食料が不足 |
| Fの袋を8→7質量 | 1日目に種と食品を併せて載せられない |
| B2の初期通貨2→0 | 1日目の食品購入資金が不足 |
| 森―畑の往復を2→3時間 | この日別計算は90日成立 |
| 森―畑の往復を2→5時間 | 3日目にFの体力不足 |

## 次の実装で確かめること

この計算は、72時間の成熟を**播種日から3日後の同じ日**に利用できると仮定し、同じ日のFとCの合流、本人の起床と情報到達、行動順、袋の中の個別ロット、土地利用権の判断を省略している。収支上の余地があっても、時刻順のために収穫・引渡し・食事が間に合わない場合は正常系失敗として記録する。[次の順2](LAND_ECONOMY_NEXT_PLAN.md)で4区画・技能2・有限の野生食料を実世界fixtureと人格判断へ載せ、まず3〜7日の因果・保存・再実行を確認する。候補値は受入のために隠れて補填せず、差分として記録する。

後続の実走と算術との差は[土地経済の90日結果](LAND_ECONOMY_V3_RESULT.md)に記録した。特に3区画では同日再播種が起き、算術の予定と異なる時刻上の失敗になった。
