# 所有農夫の畑と腐敗しない穀物

更新: 2026-10-01。雇用を導入せず、F・B1・B2が各自の畑を管理する別fixture `land-owned-farms`、規則版 `autonomous-village-owned-farms-v8` を追加した。薪は停止を継続する。旧v6・薪停止対照v7の設定・記録は保存している。

## 設定と権限

3人を穀物技能2の農夫とし、それぞれ4区画・初期種4を持つ。Fの畑は地図東側、B1は北西の自宅近く、B2は南西の自宅近く。各作物は `farmId` と `ownerId` を持ち、利用権も所有農夫に固定する。耕作・播種・収穫は受付と作業完了時に所有者を検査する。土地・作物の所有権移転、雇用、共同利用は導入していない。農夫の判断は本人の所有区画と現地で見える作物の段階から行い、離れた区画の成長状態は読まない。

穀物は食品ロットの産地情報 `species: grain` により腐敗処理を通らない。引渡し・分割・販売後も産地情報が残るので、所有者が変わっても腐敗しない。野草・ベリー・果実の腐敗設定は従来どおり。植物の生育・再生・畑の休止は変更しない（穀物6日生育、収穫後3日休止）。

各畑の初期状態は、熟した区画1、5日育った成長中の区画1、未耕作の区画2。開始前から育っていた作物を用意し、最初の6日生育をつなぐ。食品を人物の袋へ直接追加していない。農夫は空腹・在庫・体力から、自分の区画で収穫、耕作、播種、食事、休息を提案する。空腹時の収穫を定時の取引訪問より優先する。Fは従来の食料契約のため森へ往復するが、夕方には畑へ戻る。B1/B2は自分の畑で自給する。

現在のF5標準表示は[直接採集・余剰市場v9](WILD_FOOD_MARKET_V9_RESULT.md)。記録選択の「所有畑・穀物保存」または `/?village=land-economy&wood=farms` でv8を表示する。記録選択で旧v6・薪停止対照v7へ切り替えられる。畑の枠はFが黄、B1が青、B2が紫。セル選択には所有農夫と畑ID、人物履歴には所有区画数、凡例には枠色と穀物保存の設定を表示する。

検査対象は、3農夫への種・技能と4区画ずつの割当、他人の耕作・播種・収穫の拒否、穀物の期限超過後の保持と野草の腐敗、90日各日の3農夫の食事、全農作業の所有者一致、記録の再実行。旧記録も再実行できることを既存テストで確認する。
