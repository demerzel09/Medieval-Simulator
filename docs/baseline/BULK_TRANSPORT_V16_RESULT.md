# 穀物の収量・保管と荷重による運搬 v16

更新: 2026-10-02。

## 仕様

ユーザー指定により播種1から収穫20へ変更。播種にも製パンにも同じ「穀物」を使い、種の独立物品と収穫時の種の追加生成を廃止する。初期穀物は農夫各4、合計12。播種時は実在する携帯穀物を1消費する。穀物は直接食べられず腐敗しない。パン・野生食品の期限と食事量は既存どおり。

穀物の単位重量2、パン・ベリー・果実・野草1、通貨0。値はkgではなく粗い物理量。収穫20の重量40は袋の容量20・人物全体24を超えるため、作物セルに置いた本人所有の穀物庫へ収穫する。作物1区画ごとの庫は重量128まで。現地の所有者が実物を分割して袋へ積む。人格は通常5単位以下ずつ運び、4区画分の播種用在庫を販売から取り分ける。自宅の原料も運搬対象とし、携帯＋保管原料が20以上なら追加の農作業を控える。播種用も重量に含む。

地形コスト1で、1時間の移動予算240tick、1セルの必要量は10＋携帯重量。整数進捗を保存し、経路変更・障害物再探索にも適用する。無荷物時24セル/時間、重量8で約13.3セル、18で約8.6セル、20で8セル。移動体力消費は毎時間 `1 + ceil(重量/8)`。重量0/8/18/20なら1/2/4/4。重さに応じ速度は各単位ごとに低下し、体力消費は整数段階で増える。休憩・睡眠の既存回復で疲労を解消する。

実行開始時の荷重を旅行中に保持する。未知行先の距離見込みにも荷重を反映し、実測移動時間は経路と重量4単位ごとの組み合わせで記憶する。軽いときの経験を重い荷物で流用しない。必要体力を予測して休み、最大体力を超える安全余裕を待ち続けない。

## 荷重に対する行動調整

食料が不足しそうなときは経済活動より現地の可食食品・採集を優先。採集量を袋の空き重量以内にする。自宅にいる場合、重い穀物を所有穀物庫へ預けてから食料を探す。播種用在庫は食料があり農作業が必要なときに自宅から持ち出す。保管物の取り出しも現地で行う。食料採集と睡眠の必要は荷重・気温・移動時間と共に判断し、帰宅を固定日課にはしない。

v15で確認した市場待機の時刻も新規則で修正。移動提案時には待機時計を始めず、現地で待機開始し、退出後の判断で前の時計を消す。

## 範囲
