# 植物セルで採集する移動・待機の修正

> 資料区分：旧版・旧段階の実験記録／計画。本文の「現行」「最新」「次の作業」は記載時点のもの。現在の実装は [STATUS](../STATUS.md)、今回の作業は [NEXT_SESSION](../NEXT_SESSION.md) で確認する。

更新: 2026-10-02。ユーザーが森・畑の文字セルに人物が留まる問題を指摘したため、移動と待機を確認した。旧v9の採集は1時間内に対象まで往復し、時刻境界では必ず出発セルへ戻っていた。農夫にも作業対象がないと畑の中心へ帰るルールがあった。これは表示だけの問題ではなく、simと人格の簡略化だった。

## 修正

別fixture `land-local-work`、規則版 `autonomous-village-local-work-v10` を追加。旧記録はそのまま再実行可能。

- 野生採集を通常の `travel` と現地の `gather_plant` に分離した。到着する前には採集できない。
- 採集は1単位につき1時間・体力1。野草2単位は2時間、ベリー3単位は3時間、その植物セルで作業する。到着時と作業完了時に在庫と生育段階を確認する。
- 採集後は植物セルに留まり、その場で食事や休息を行う。森の中心への自動往復は使わない。
- 所有農夫は各作物セルへ移動して農作業する。作業対象がなければ今の作物セルで待機し、畑の中心への移動を提案しない。自分の畑の外にいる場合や市場から戻る場合は、既知の自己所有区画へ向かう。
- 現地観察・基礎採集能力・再生待ち・所有権・在庫・代金は維持。余剰売買の買い手待ちは市場で行う。食料があるときの待機、生育待ち、休息は残る。

例としてSの初日は、1時に市場から森へ、2時に野草セルへ移動、3時に現地採集を開始する。競合で先に採られた場合は別の見える植物へ移る。9時に別の野草セルへ移動し、10〜12時に採集、12時にその場で食べる。採集が1時間の往復に隠れることはない。
