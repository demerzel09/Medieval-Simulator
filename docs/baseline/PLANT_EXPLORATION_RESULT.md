# 食用植物の局所探索と往復採集

更新: 2026-09-28。[全域版](WIDE_WORLD_V5_RESULT.md)では植物をセルに置いていたが、人物が自分で探して採る行動はなかった。野生ベリーと薪は森の固定資源で、果樹・野草の採集操作は人物の通常判断につながっていなかった。この不足に対し、別fixture `land-explore` と規則版 `autonomous-village-exploring-land-v5` を追加した。旧記録は維持する。

## 行動と検証範囲

- Fに植物発見技能4を設定し、本人の現在セルからチェビシェフ距離4以内の植物だけを観察に渡す。初めて見た植物は `plant_discovered` Eventに残す。技能0なら植物の発見・往復採集は発生せず、従来のベリー採集を選ぶ。
- 森の周辺に別セルの野草2株と果樹1本を置いた。Fは最初の3日間、空腹時に実際に観察した熟した植物を選び、A*でそのセルまで歩き、1個採って森へ戻る。往復は経路コスト24以内で1世界時間の作業。各通過セルを `travel_step`、現地収穫を `plant_gathered` として記録する。道中のセルを塞ぐと経路を計算し直す。
- 食品ロットの産地は採った植物セルを指し、Fの鞄に本人所有で入る。Fはそれを食べる。植物の在庫・再生と食品の保存則を共有する。

```bash
npm run autonomy:village -- 90 --scenario land-explore --daily
npm run autonomy:village -- replay fixtures/recordings/autonomous-village-exploring-90.v2.json.gz
```

F5の「自律: 土地経済90日の植物探索デバッグ画面」または `/?village=land-economy` で[90日記録](../../fixtures/recordings/autonomous-village-exploring-90.v2.json.gz)を開く。初期表示は1日目01:00のFで、5分刻みで再生すると2時の往復採集を見られる。画面の分位置は、時間内の移動ステップを均等に割り当てた再生位置であり、simの判断・生育・在庫更新は引き続き世界時間単位。

## 結果と未実装

seed 240924の正常90日で5人全員が毎日1食と薪1を使用した。食品の収穫/消費は各450で、内訳は穀物435、野生ベリー12、探索した野草・果樹3。薪の採集/使用は各450。ウサギの出生/死亡は各6、末日2匹。記録から判断応答を再実行して状態・Eventハッシュが一致した。旧全域版の別記録も再現可能。

現在の探索は森周辺4セルと最初の3日の食用植物に限定する。遠くの未知の植物へ向けて地形を探索する行動、植物ごとの識別技能、複数人の採集競合、木の伐採地点、野生ベリーの複数株への分散は未実装。固定の森資源を全面的に置き換えた結果としては扱わない。これらを広げるときは商取引と作業時刻が変わるため、90日生活を再検証する。
