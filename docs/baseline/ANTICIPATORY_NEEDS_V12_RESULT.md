# 欲求・経験と予防行動 v12

更新: 2026-10-02。`land-needs` はv11の穀物保存・パン加工を継いだ独立した規則版。身体と環境、本人の経験記憶と予測、備蓄に応じた行動の初期実装を追加した。技能獲得・職選択による経済の持続性はまだ達成していない。

## 世界の法則

実装は `packages/sim/needs-body.ts` と `autonomous-world.ts`。世界は目的地・仕事・食事を選ばない。

- 外気温は24時間周期で変化し、明け方8℃・午後22℃となる。本人の家では保温効果を10℃加える。これは単一地図の暫定条件で、天候・季節ごとの気温や他の避難場所は未実装。
- 寒さは16℃未満の滞在で増え、暖かい場所で減る。寒さ8以上の間は毎時体力1を消耗する。寒さによる消耗時間を記録するが、低体温症・病気・死亡は追加していない。
- 活動体力と睡眠不足を分ける。起きている間は睡眠不足が毎時1増え、睡眠中は自宅で毎時2、屋外で毎時1減る。睡眠不足は0〜48の抽象量で、実時間の睡眠必要量そのものではない。睡眠不足24以上で起きていると、4時間ごとに体力1をさらに消耗する。
- 睡眠は8時間の行為で、実際に寝た時間に応じて体力も回復する。自宅で毎時2、屋外で毎時1。短い休憩は2時間で毎時体力2を回復するが、睡眠不足は減らない。
- 睡眠は途中保存・再開と `wake_up` Commandによる中断に対応する。中断前の回復は残し、8時間分を一括で付与しない。他人の家での睡眠は利用権なしとして拒否する。睡眠中の本人による自律的な中断判断は後続。
- 空腹の追加は日付変更ではなく、人物別の経過24時間で行う。初期の経過は18時間なので最初の必要は6時間目。空腹は当面整数の食事必要量で、連続的な栄養モデルではない。
- 穀物は直接食べられず、運搬・保存後に加工する。穀物は腐敗せず、パンは製造日から3日で腐敗する。薪・雇用は停止継続。

## 本人の記憶・予測・選択

実装は `packages/ai/anticipatory-needs.ts`。入力は既存の `PersonalityModel` 境界を使い、世界の未来や他人の在庫は参照しない。

1. **経験記憶**：本人の観察前後の身体、場所、時刻、選んだ行動、経過時間、根拠のEvent IDを保存する。強い寒さ・睡眠不足と大きな回復を重要な経験として残す。感情は現段階では身体の悪化・回復を代理指標とし、独立した感情モデルは未実装。
2. **通常の経験も集計**：寒さの変化、観測した時刻別の屋外気温、経路ごとの移動時間、屋内・屋外の睡眠回復を、件数・平均・ばらつきで蓄積する。詳細な経験は最大24件（重要な過去16件と直近8件）、時刻別気温は最大24枠。
3. **予測**：近い身体状態・場所の条件の経験を最大3件参照し、集計した変化と初期の信念から、作業継続・帰宅と睡眠・現在地の休憩・現在地の睡眠・屋外への移動の見込みを作る。初期の信念は夜の冷え、移動距離、屋内睡眠の利点などで、fixtureの正しい将来を読んだものではない。予測範囲は最低6時間、家への移動と余裕を含める。自宅から出る場合は8時間の屋外露出も確認する。
4. **行動**：予測した寒さや睡眠不足、移動負担から避難・睡眠を選ぶ。安全な現在地での睡眠が遠い家への移動より有利な条件も扱う。選択した目的を保持し、移動拒否・身体の変化などで見直す。
5. **食品**：自食用の2食を販売用とみなさず、次の空腹に備えて加工・採集する。保存原料と可食在庫を合わせた備蓄の目安12食を使って農作業を抑える。これは初期の本人の備蓄方針で、世界による生産割当ではない。
6. **販売**：実際の余剰がある場合だけ提示し、待機は3時間を目安にする。販売不成立が続くと再訪までの間隔を広げ、成立した取引結果で見直す。正常例では販売用の余剰を作らず売買0件となるため、この例で食品市場の持続性を主張しない。

予測は少数の候補と身体・備蓄の優先判断を組み合わせたrule人格の初期版。一般的な計画木探索、任意の行動列の最適化、ニューラルモデルやQ学習は導入していない。帰宅・食事を固定時刻に命令せず、本人の初期知識・観測・記憶に基づく判断とする。未選択の行動の結果を観測済みの事実として学ばない。

## 記録・画面・実行

```sh
npm run autonomy:village -- 90 --scenario land-needs --daily
npm run autonomy:village -- replay fixtures/recordings/autonomous-village-needs-90.v2.json.gz
```

F5「自律: 土地経済90日の生態デバッグ画面」の標準をv12へ変更。気温・寒さ・睡眠不足、予測した寒さ、対処に必要な時間、参照する記憶と判断理由を表示する。進行中の行為はEventから再構成し、地図の「Z」は睡眠を示す。旧v11と以前の記録も選択可能。

記録は本人の記憶と判断応答を含み、v12の規則版で再実行する。圧縮記録は約8.7 MiB、展開JSONは約161 MB。経験を各判断に保存するためv11より大きい。記憶の共有辞書や差分保存による圧縮は今後の改善対象。
