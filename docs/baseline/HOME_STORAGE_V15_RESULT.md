# 人物のステータスと自宅保管 v15

更新: 2026-10-02。食品市場v14を継承し、家の物品収納と実際の状態を追えるデバッグ表示を追加した。技能獲得・職選択・薪・雇用は追加しない。

## 表示

同じF5の生態デバッグ画面、URL `/?village=land-economy` の標準はv15。「人物の履歴」「ステータス」「凡例」のタブで切り替える。v15ではステータスを初期表示し、人物と経路の選択を同じ枠に置く。履歴では既存の判断理由・売買を残す。状態記録のJSONは行動Event一覧には表示しない。

ステータスは次のカードに分ける。

- 身体：体力／最大体力、気温、空腹、睡眠不足、屋内外、食事からの経過。
- 身体の快・不快：空腹・寒さ・疲労・眠気を0〜100%のバーで表示。
- 携帯中：財布の現金、携帯重量／容量、食品・種・薪の数量・重量・期限・販売提示状態。
- 家：本人の収納箱と自宅穀物庫にある現金・物品、重量／合計容量。
- 市場：市場の本人所有の穀物庫、Sの販売在庫にある物品。

物品名を展開するとID・所有者・物理的な保管先を確認できる。穀物は「腐敗なし・原料」、パンなどは残りの日数で示す。質量は粗いシミュレーション単位で、通貨の質量0はv14を継承する。携帯容量は身体の上限24で、袋の物品上限20も物理側で検査する。家の合計容量168は収納箱40と既存穀物庫128の合計であり、一つの箱の上限ではない。

## 快・不快の意味

独立した感情や学習済みの行動価値を追加したものではない。現在の身体負担を読み取りやすくする表示指標である。

空腹は `hunger/3`、寒さは `cold/12`、疲労は `1−energy/maxEnergy`、眠気は `sleepDebt/24` を0〜1に制限して百分率にする。不快は4項目の最大、快適さは100から不快を引いた値。同時に原数値も表示する。この表示値を世界の行動命令や予測の正解として人格に渡さない。予測と行動価値の今後の学習は[小モデル設計](MODULAR_PREDICTION_AND_ACTION_PLAN.md)を継続する。

## 家の収納

各人物の家に本人所有の収納箱を追加する。食品・種・薪・現金を置ける。物品には `store_home` / `take_home`、現金には `store_home_cash` / `take_home_cash` を使う。実際に自宅にいること、本人所有、正の整数数量、在庫、容量を検査する。部分収納では物理ロットを分割し、食品の産地・収穫日・製造日を引き継ぐ。預けても所有者は変わらず、実在する現金が財布と箱の間を移るだけで新規所得を作らない。

家に置いた食品も通常の腐敗処理を受ける。パンは製造日から3日、穀物は腐敗なし。家にある食品や現金を遠隔で食べたり払ったりせず、自宅で取り出してから携帯する。取り出し元には既存の自宅穀物庫も使える。所有農夫の耕作と市場の製パン技能・場所条件は維持する。

本人の初期ruleは身体の保護判断を優先した後、自宅で現金8を残して余りを預け、携帯現金4未満なら8まで補充する。携帯食品2食を目安に余りを保管し、足りないときには保管食品を持ち出す。保管のための帰宅時刻は固定しない。収納行動は初期の有限ルールであり、備蓄量の学習ではない。自宅の収納内容を人格へ渡すのは本人が自宅にいる場合だけ。

## 記録と90日の実測

`person_status` を初期時点と各時間の処理完了後に残す。実物の物体木と身体から生成し、人格の最後の観察値とは区別する。カードは表示Eventまでに到達した状態記録を使用し、未来の在庫を表示しない。時間内の移動位置は従来の分補間で、所持品・身体は状態記録の時点を明示する。全量の状態保存・再開と、判断応答からの世界再実行を継承する。旧v14以下の規則・記録は維持する。

## 検証対象

現地・所有・数量・容量の拒否、現金保存、食品の部分移転と産地、家のパンの腐敗、自宅穀物庫からの取り出し、収納箱欠落時の保存検査、途中保存再開、90日記録再実行、記録状態と実物状態の照合を検査する。ブラウザではカードと快不快バー、家の現金、巻き戻した初期状態、履歴タブ、旧記録8種類を確認する。

検証：旧版37ファイル204/204、最終版v15対象5/5、ブラウザ9/9、型検査を含む本番ビルド・コンテンツ検査・文書リンク・差分検査に成功。全体38ファイル209件の実行中に収納箱検査と取り出し元ログを補強したため、途中版で不一致となったv15の2項目は最終版の5/5再実行で確認した。新90日記録の世界再実行と、10日の途中保存再開・状態の実物照合を検査した。
