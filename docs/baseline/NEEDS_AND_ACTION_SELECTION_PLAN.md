## 原則

帰宅・就寝・食事・販売の時刻を人物へ指示する日課を追加するのではなく、世界の条件と本人の認識から行動する理由を作る。家に帰る必要がなければ、屋外に留まる判断も妥当である。帰宅回数を成功指標にはしない。

世界は身体と環境の変化、試行の可否・時間・結果を確定する。本人は身体から感じる欲求、届いた情報、自分の記憶・技能・備蓄・利害と、そこから予測する将来の結果から行動を選ぶ。現在の不快が強まるまで待たず、対処の所要時間を踏まえて予防行動を選べるようにする。世界が最善の行動や目的地を渡すことはしない。rule人格の判断方法を、NN・LLM・人間を含むすべての人格に必須の採点式として課さない。

## 世界側と人物側の責務

| 対象 | 世界側の正本・法則 | 本人に届く情報と判断 |
| --- | --- | --- |
| 気温と保温 | 時間で変化する外気温、場所の遮蔽・保温、滞在による寒さと消耗 | 現在感じる寒さ、観察・経験で知っている場所の効果から避難や作業継続を選ぶ |
| 活動と疲労 | 移動・荷重・作業の消耗、活動可能な体力 | 現在の疲労と見込む移動・作業の負担を比較する |
| 覚醒と睡眠 | 実睡眠履歴から求める不足、覚醒で高まる睡眠圧、昼夜のリズムと回復 | 現在と先の眠気、既知の睡眠場所、そこへの移動負担から睡眠・短い休憩・作業を選ぶ |
| 食事 | 食料の所在・所有・栄養・腐敗、食事による空腹の変化 | 空腹、自分の可食在庫と原料備蓄、既知の入手先から食事・採集・加工・購入を選ぶ |
| 備蓄と生産 | 穀物・パン・種・土地の現物、作業時間と収量 | 自食用に残す量、予想消費、生育待ち、本人が見込む販売機会から生産量を決める |
| 販売 | 提示・購入・現物と代金の移転・腐敗を確定 | 届いた提示、実際の売れ行き、待機時間と移動負担から販売・撤退・見直しを選ぶ |

身体信号は本人へ到達する刺激として扱う。遠隔地の現在の温度、未発見の避難場所、他人の在庫・空腹や市場の全需要は渡さない。本人の場所の記憶と見込みは、世界の真実と分けて保存する。

## 身体と場所の初期範囲

- 活動で減る体力、覚醒で高まる睡眠圧、実睡眠量に対する不足、今の眠気を分ける。短い休憩で体力が回復しても、十分な睡眠の代わりにはしない。待機や入眠待ちだけで睡眠したことにはしない。
- 睡眠は開始・進行・中断・完了を持つ時間のかかる行為とする。回復は実際に寝た時間と場所の条件から計算し、中断した場合も経過を残す。
- まず昼夜の外気温と、家・屋外の遮蔽・保温・睡眠条件を扱う。家が有利な条件を物理法則として設定しても、そこへ向かう命令にはしない。
- 穀物庫と家の居住・睡眠条件は別の機能とする。市場に穀物庫があるだけでは、快適な睡眠場所にはならない。
- 家や休息場所の利用権と物の所有権を区別する。他人の家を知っていても、自由に利用できるとは限らない。
- 気温の周期・消耗率・睡眠の必要量・回復率の数値は次の小fixtureで検算する設計対象。寒さの導入を理由に、停止中の薪需要や木こりを再開しない。

## 本人の判断の組み立て

最初のrule人格では、本人が実行できる候補（食べる、採集、加工、農作業、販売、休憩、睡眠、移動、待機）を作り、欲求の切迫度、予想される効果、時間・体力・移動の負担、備蓄と仕事の見込みから選ぶ。これらは本人の見積もりであり、全知の最適解ではない。

例えば寒い夜に疲れている人物は、近い家での回復と帰宅の負担を比較する。家が遠ければ近くの利用可能な避難場所で休むこともあり、暖かく十分回復できる条件なら屋外で寝ることもある。同じ人物でも、気温・眠気・家までの距離が変われば選択が変わることを確かめる。

選んだ目的と途中までの進捗を記憶に残し、毎回無条件に目的地を選び直して往復しない。身体状態の悪化、観察した資源の枯渇、道の閉鎖、届いた取引情報などで再検討する。目的の継続や切替も本人の判断とする。

販売が成立しなければ、見込みを更新し、持ち帰り・自食・加工量の削減などを選べるようにする。単にパンを2食持っていることを「1食は余剰」とはみなさず、自食用の備蓄と販売用に回す量を本人が決める。

## 経験記憶と予測による予防行動

現在の快・不快への反応だけでは、寒くなってから家へ向かっても到着前に消耗し、疲れ切ってから眠ろうとしても移動できない場合がある。本人は強い快・不快を感じた経験を記憶し、似た状況で今後起こりそうな変化を予測して、手遅れになる前に行動する。快は暖かさ・満腹・十分な睡眠など本人が感じた状態や回復、不快は寒さ・空腹・眠気・疲労などの強さと継続として扱う。v12では寒さ・睡眠不足・回復の変化を代理指標とし、独立した感情の尺度は後続とする。

### 記憶する内容

経験は本人がその時に知っていた情報だけから構成する。

- **状況**：時刻、現在地と既知の場所の特徴、感じた気温・身体状態、手持ちと本人が記憶している備蓄。
- **経過**：直前に選んだ行動や待機、移動・作業にかかった時間、快・不快が現れるまでの遅れと継続時間。
- **結果**：感じた快・不快の種類と強さ、行動後の身体の変化、回復や失敗を知った時刻。
- **根拠と確かさ**：本人へ届いた観察・結果の識別子、経験回数、結果のばらつき、最後に確かめた時刻。推測した原因と実際に観察した経過を区別する。

強い経験を優先して保持するが、強い感情がなかった日常の移動時間や回復の経験も予測の材料として蓄積する。一度の経験を普遍的な世界法則とみなさず、古い経験の確かさと適用範囲を見直す。詳細な記憶と反復経験の要約を分け、記憶容量・忘却の具体値も設計対象とする。

### 最初のrule人格での予測と選択

1. 今の状況に近い経験を本人の記憶から取り出し、何もしない場合と、知っている候補行動をとる場合の身体の変化・快不快・所要時間を見積もる。似ている根拠と、異なる条件を残す。
2. 現在の切迫度に加え、将来の不快の強さ、起こる見込み、回復の見込み、移動・準備・作業の負担と不確かさを比較する。予測範囲は候補の対処に必要な時間を含める。
3. 危険が強くなると見込む時点から、対処に必要な時間と本人が見積もる余裕を差し引き、予防行動を開始する。余裕は移動時間のばらつきや見積もりの確かさに応じて変える。
4. 途中の身体信号や到達情報で予測を更新し、目的の継続・切替を選ぶ。実際の経過が届いたら予測との差を記録し、次の見込みを修正する。

例えば以前に夜の畑で強く冷え、家までの移動にも時間がかかった人物は、翌日の夕方には寒さが弱くても、知っている日変化と移動の経験から先に帰宅できる。屋内でよく眠れた快の経験も、次の睡眠場所を選ぶ根拠になる。気温や道が変われば同じ時刻・同じ行動を無条件に繰り返さない。

予測は人格内の実装であり、世界が未来の正解や隠れた状態を渡す機能にはしない。未経験の危険には、本人の初期の知識、届いた注意や他者の説明、現在の兆候から不確かさを含めて対応する。初期知識や伝聞にも出所と確かさを持たせ、必ず一度被害を受けて学ばせる設計にはしない。

予防して不快が起きなかった場合、「予防しなくても安全だった」とは学習しない。観察できるのは選んだ行動の結果であり、選ばなかった行動の結果は仮説として残す。記憶からの予測だけで完全な安全や最適判断を保証することもしない。

## 実装順と受入

v12は以下の順1〜4の初期版までを接続した。広い条件への一般性や市場の持続性は未受入。

1. **判断の整理**：手持ちと保存原料を区別し、消費見込み・自食用備蓄・販売履歴を判断に反映する。目的の継続と再検討を記録し、売れない毎日の市場往復や無制限の生産を見直す。
2. **身体・環境の小fixture**：昼夜の気温、場所の保温、活動疲労と睡眠不足、休憩と睡眠を区別する世界法則を実装し、時間・回復・中断・利用権を検査する。
3. **経験記憶・予測と本人の選択へ接続**：強い快・不快と通常の行動経過を記憶し、身体信号・既知の場所・経験から将来の結果と対処時間を見積もる。帰宅・別の場所での睡眠・屋外滞在・作業継続を比較し、不快が強まる前に予防行動を選べるようにする。
4. **食品経済との統合と対照**：温暖／寒冷、近い家／遠い家、利用可能／不可、十分な睡眠／中断、在庫・買い手の有無を変えて、小fixtureと90日記録で選択・消耗・在庫・取引の差を測る。
5. **技能獲得・職選択へ**：[食品経済の計画](FOOD_ECONOMY_SKILLS_PLAN.md)へ接続する。持続性の最初の目標は、技能と職を需要に応じて選んだ経済とする。雇用・木こりは引き続き後続。

予測の対照として、同じ現在の身体・環境でも経験の有無で行動が変わること、家が遠いと必要な対処時間が長くなること、温暖化・道路閉鎖・経験と異なる結果によって予測が更新されることを検査する。強い不快の経験だけでなく、快・回復の経験が場所の選択に作用する対照も設ける。現在の不快だけを見る人格との比較では、予防行動の開始時点・最大の消耗・移動の負担を記録する。

受入は「毎晩全員が帰宅」「全員が必ず生存」ではなく、条件の差が世界の消耗・回復と本人の選択に因果として反映されることとする。外で休む方が有利な対照も残し、隠れた世界情報への依存を検査する。

身体・環境の変化、本人への情報到達、候補の見積もり、参照した経験、予測の対象時点・確かさ・対処時間、選択理由、目的の切替、試行と結果、実際の経過に基づく予測の更新を記録する。記憶と睡眠途中の状態も保存し、同じ入力・応答で再実行が一致することを確認する。説明用の理由で世界の真実を後付けせず、判断時に使った情報を根拠とする。
