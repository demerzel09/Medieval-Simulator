# 5人の90日生活: 実行可能性の数表

更新: 2026-09-27。[90日計画](AUTONOMOUS_90_DAY_PLAN.md)の段階0。版付き仮定は[fixture](../../fixtures/autonomous-90.ts)、90日分の算術検算は `npm run autonomy:feasibility`（`-- --daily` で日別）で再現する。**これは一連の行動が可能な資源・時間・通貨の条件を示す計算であり、人物がその行動を選ぶことや世界が90日続いたことの証拠ではない。**

## 小世界と必要量

Sは市場、Fは食料パッチ、Cは両者を結ぶ運搬人、B1/B2は薪パッチの利用者。Fだけがこのfixtureの食料パッチを採取でき、B1/B2だけが薪パッチを採取できる初期権利を置く。市場と食料/薪パッチは片道1時間、Bの家から薪パッチ・市場を回って帰る経路は合計3時間とする。B以外も薪を使う理由は各自の住まい/仕事場の暖房であり、Sの売場の営業だけには依存しない。各人は1日1食と薪1本を使う。本人が食事・燃焼を選ばなければ、算術上の供給があっても必要を満たしたことにはならない。

| 1日の食料 | 数量 | 1日の薪 | 数量 |
| --- | ---: | --- | ---: |
| Fが採集 | 5 | Bのうち現金の少ない人が採集 | 3 |
| Fが自分で食べる | 1 | もう一人が採集 | 2 |
| Sが仕入れる | 4 | B1/B2が自分で使う | 各1 |
| Sが自分で食べる | 1 | S/C/FがBから買って使う | 各1 |
| SがC/B1/B2へ売る | 各1 | 全員の消費合計 | 5 |

食料・薪パッチは各8から始まり、2日目以降の開始時にそれぞれ5再生し、容量は8。したがってこの計算では毎日5採ると日末残量3、90日累計で各450生産・450消費となる。食品の使用可能期間は収穫日を含む3日間を想定するが、予定どおりなら全量を当日消費する。再生が4に下がれば予備3を使い切り、5日目に不足する。この資源予備は人物が取り逃した食事を自動補填しない。

## 通貨の循環

初期通貨はS=20、F=0、C=0、B1=0、B2=2で、総量22。食品のF提示単価1、Sの売値6、Cの運賃10、薪単価4は**計算用の候補条件**。将来の実行時はS/F/C/Bが情報と利害から提示・承諾し、世界がこの価格を強制しない。CはSから運賃10を受け、S所有の仕入金4を現地へ運ぶ想定。下表のS→Fは、Cを介した実物の支払を所有者間で集計したもの。

| 人物 | 毎日の入金 | 毎日の支出 | 日次差額 |
| --- | ---: | ---: | ---: |
| S | 食料3食の販売18 | Fへの仕入4、Cへの運賃10、薪1本4 | 0 |
| F | 食料4食の販売4 | 薪1本4 | 0 |
| C | 運賃10 | 食料1食6、薪1本4 | 0 |
| 薪を3本採るB | 薪2本の販売8 | 食料1食6 | +2 |
| 薪を2本採るB | 薪1本の販売4 | 食料1食6 | −2 |

Bはその朝の現金が少ない方が3本、もう一人が2本採るという**可能な本人ルール**で交替できる。B2の初期2が初日の不足を賄い、日末現金は奇数日にB1=2/B2=0、偶数日にB1=0/B2=2。Sは運賃・仕入・薪を売上前に払っても財布に最少2残る。90日末もS=20、F=0、C=0、B1=0、B2=2で総量22。Cが仕事を拒む、Bが薪を納めない、実売値が変わる場合、この循環は崩れてよい。

## 時間・荷重・体力の上限

採集1単位1時間、荷役・引渡し・買物・食事・燃焼をそれぞれ所定の1時間、Cの荷役は往復で計2時間、睡眠/休息8時間と仮置きする。初期体力8、上限10。仕事と移動の1時間につき体力1を使い、休息8時間で8回復する。算術検算は毎日の支出後に休息する順序で体力が負にならないことを確かめる。行為の重なり、実際の時刻順と道中の位置は次段の物理simで検証する。

| 人物 | 仕事・移動・食事・燃焼・休息の最大合計 | 最大の体力支出 | 必要な荷重枠 |
| --- | ---: | ---: | ---: |
| S | 15時間 | 5 | 食料4、薪1、売上通貨 |
| F | 17時間 | 7 | 採集食品5 |
| C | 15時間 | 5 | 食品4。運賃10と預り金4を同時に持つ場合の総質量18以下 |
| 薪3本のB | 18時間 | 8 | 薪3 |
| 薪2本のB | 16時間 | 6 | 薪2 |

fixtureの容量はFの食品袋5、Cの食品袋4、Bの薪袋3、Cが人ごと運ぶ総質量20。最も重い瞬間を食品4＋通貨14＝18と見積もる。実装時は身体・袋・財布の包含関係から実荷重を再計算し、積めなければ作業が進まないようにする。時間の合計が24以下でも、相手の到着待ちや支払順が成立することはまだ証明していない。

## 計算で分かった境界と次段

算術検算は90日すべてで5人の食事・薪使用、通貨保存、24時間・休息による体力回復枠、荷重上限を満たす。対照ではB2の初期2を外すと1日目の食料購入、薪の再生を4にすると5日目の採集、Cの運搬上限を17にすると予定した積荷、薪の採集時間を5倍にすると1日の時間が成立しない。食料売値を6から5へ下げても予定した支払が続かない。

これは初期権利、提示価格、全員が取引に応じること、資源再生5、毎日ちょうど間に合う情報伝達を仮定した細い正常条件である。次の[段階1](AUTONOMOUS_90_DAY_PLAN.md)では、人物ごとの起床と刺激配送を同じランナーに載せる。さらに物理simと契約権限をつないだ後、遅延・拒否・価格変更でも本人がどう行動するかを測る。算術上の交替日課を世界が実行してはならない。
