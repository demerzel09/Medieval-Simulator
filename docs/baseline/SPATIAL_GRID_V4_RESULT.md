## 実装した空間

- 論理地図は40列×24行、1セル32ピクセル。画面の描画領域は正確に1280×768ピクセルのCanvas。
- 岩、尾根、建物の矩形セルを通行不能にした。A*は8近傍で斜めの角抜けを禁止し、経路の各セルを時刻ごとに進む。移動途中でセルが塞がれれば現在位置から再探索する。画面の行先選択は同じA*で経路を重ねる。
- 穀物4区画はそれぞれ固有のセルと生育段階を持つ。Fは現在セルの周囲1セルを観察し、対象区画のセルへ移動してから耕作・播種・収穫する。果樹、野草、草、野生ベリーも別セル。ウサギはセルからセルへ、餌植物への経路を探索して動く。
- 植物の生育、人物・動物の移動、作物作業、売買・食事は同じ世界からのEventで記録され、Canvasは[空間版90日記録](../../fixtures/recordings/autonomous-village-spatial-90.v2.json.gz)を時刻ごとに描く。画面用の見せかけの移動や作物成長は作らない。

```bash
npm run autonomy:village -- 90 --scenario land-spatial --daily
npm run autonomy:village -- replay fixtures/recordings/autonomous-village-spatial-90.v2.json.gz
```

この版の画面は全域版に置き換えた。記録はCLIの `replay` で引き続き検証できる。

## 正常90日と検証

空間版は毎日の歩行が増えるため、初期・最大体力26と休息回復14を別fixtureに明示した。旧5×5土地経済の体力20・回復8は変更しない。空間版の実測では5人全員が90日間毎日1食・薪1を使い、食品450の内訳は穀物435・野生ベリー15、薪450、通貨26保存。日61〜90の150食は穀物。ウサギは出生6・死亡6で末日2匹。空間版の記録は30,508 Event、圧縮約0.92 MBで、人格応答からの90日再実行が状態・Eventハッシュまで一致した。

テストは作物区画のセル重複なし、Fが作物と同じセルでのみ作業すること、岩と尾根の迂回路、移動中の落石による経路再探索、動物の移動、90日の日別食事と記録再実行を確認する。

32ピクセルは表示単位で、人物の位置と衝突判定はセル単位。木や岩の絵は簡単なピクセル図形。地図には960セルあるが、作物4区画と補助植物4箇所の生育を検証しており、全セルが農地という意味ではない。現時点の移動コストは全通行可能セルで1。将来の道・草原・森・傾斜ごとのコスト差は未設定。全域を使う人口・生態・土地利用権の一般性も未検証。
