# 地図全域を使う土地経済

> 資料区分：旧版・旧段階の実験記録／計画。本文の「現行」「最新」「次の作業」は記載時点のもの。現在の実装は [STATUS](../STATUS.md)、今回の作業は [NEXT_SESSION](../NEXT_SESSION.md) で確認する。

更新: 2026-09-28。旧[空間版](SPATIAL_GRID_V4_RESULT.md)は40×24セルのCanvasと経路計算を持っていたが、実際の市場・家・畑・森・草原は中央約9×9セルに集中していた。この配置では広い地図の移動と土地利用を検証できなかった。別fixture `land-wide` と規則版 `autonomous-village-wide-land-v4` を追加し、旧記録は再実行可能なまま残した。

## 実装と配置

- 地図は40列×24行、1セル32ピクセル、画面は1280×768ピクセル。市場(4,12)、森(16,12)、畑(34,5)、B1宅(2,4)、B2宅(3,20)、草原(35,19)に分散した。穀物4区画は畑付近の別セル(34,4)、(35,4)、(35,5)、(35,6)。野生ベリー、果樹、野草、草も別のセルに置く。ウサギは草原から(31,21)の草まで4セル移動して採餌する。
- 岩・尾根・建物・大岩の矩形セルは通行不可。8近傍A*は角抜けを禁止し、閉鎖や移動中の占有で現在セルから経路を再探索する。地形コストの構造はあるが、今回の通行可能セルのコストはすべて1。
- 1世界時間につき最大24の経路コストを進む。通過した各セルを `travel_step` Eventに記録する。画面は5/15/30/60分刻みの手動進行・再生・停止・4倍速の早送りを持つ。分単位の位置は、その時間内のEvent順を等間隔に割り当てた**表示上の目安**であり、シミュレーション自体は1時間単位。耕作・播種・成長・収穫、動物の移動と摂食は世界状態の変化から描画する。

```bash
npm run autonomy:village -- 90 --scenario land-wide --daily
npm run autonomy:village -- replay fixtures/recordings/autonomous-village-wide-90.v2.json.gz
```

F5の「自律: 土地経済90日の全域デバッグ画面」または `/?village=land-economy` は[保存済み90日記録](../../fixtures/recordings/autonomous-village-wide-90.v2.json.gz)を表示する。日・時刻・分・再生の刻み・人物・経路行先を選べる。セルをクリックするとそのセルの植物と動物を確認できる。以前に地図を横切っていた黄色い□は、選択人物から選択行先への**A*計算経路**を全セルで囲む表示だった。現在は初期状態で非表示にし、行先を選ぶと黄色い一本線で示す。この線は実際の通過履歴ではない。

## 実走と検証

単一seed 240924の正常90日で、5人全員が毎日1食と薪1を使用。食品の収穫/消費は各450、穀物435食、野生ベリー15食、薪の採集/使用は各450、通貨26を保存した。記録は41,324 Event、うち人の `travel_step` は11,954件、通過セルは79種類、移動範囲はx=0〜35・y=4〜20。畑の東側まで人が実際に歩く。移動中の落石で再探索するテスト、90日記録の判断応答からの再実行、旧空間・旧5×5記録の再実行も成功した。

検証は単一地図・単一seed・5人・rule人格に限る。耕作可能セルの一般的な土地判定、地形別の移動コスト、畑の拡張、動物が広域を採餌する生態は次の段階。現時点で植生を持つのは設定した植物セルであり、960セルすべてが作付け済みという意味ではない。
