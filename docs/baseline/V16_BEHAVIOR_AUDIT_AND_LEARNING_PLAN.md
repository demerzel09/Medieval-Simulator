# 自律村の不自然な行動と経験学習の改善計画

更新 2026-10-02。

現在の穀物運搬版v16を、保存済み90日記録と実装から監査した。主な問題は、自宅での積み込みと荷卸しの反復、実際の食事間隔と表示値の不一致、冷えと睡眠不足を含む移動負担の予測不足である。全員の合計90食と保存則が成立していても、行動の無駄や身体の負担は残っている。

対処は、観測する身体状態を正しくし、目的を持った行動と結果を対応づけ、経験から時間・体力・回復・成果の見込みを更新する順で進める。物品の種類に依存しない仕組みとし、穀物の荷卸しだけを特別な学習対象にしない。今回の変更は監査と設計文書の追加であり、以下の改善案は未実装である。

## 監査対象と測定方法

- 実装基準はコミット `947827b`、規則 `autonomous-village-bulk-transport-v16`。
- 対象は[同梱90日記録](../../fixtures/recordings/autonomous-village-bulk-transport-90.v2.json.gz)。seed 240924、5人、2,160時間。記録の最終状態は `bf14d42c`、Eventは `80162b02`。
- `decisions` の本人の入力・理由・試行と、`events` の実行結果・初期および毎時間末の `person_status` を照合した。監査者が読める全員の状態を、そのまま人格へ渡す設計にはしない。
- 積み戻しは、穀物庫から積んだ物体が、到着Eventを挟まず同じ自宅庫に同量戻り、間隔が8時間以内の組を数えた。物体IDを照合し、単に保管回数が多いことを問題とはしない。
- 空腹時間は時間末の空腹が正のサンプル数。食事間隔は連続する本人の `ate` の発生時刻差。採集失敗・食事なしの日・腐敗は発生Eventを数えた。判断回数と経過時間は区別する。

単一の地図・初期条件・rule人格に対する監査である。以下の数字はこの記録の結果であり、他の条件の一般性や新しい案の効果を示すものではない。

## 食事の経過時間と身体状態

[身体更新](../../packages/sim/needs-body.ts)は `mealHours` を毎時間増やし、24に達すると24を引いて空腹を1増やす。[食事処理](../../packages/sim/autonomous-world.ts)は空腹を1減らすが、この時計をリセットしない。[ステータス](../../packages/sim/village-status.ts)と[画面](../../apps/web/village-debug.tsx)はそれを食事からの経過として扱っている。周期の位相と最後の食事からの時間が混同されていることは、コードから確認できる不具合である。

例えばFはhour780の野草摂食 `e_029437` からhour836の果実摂食 `e_031598` まで56時間空く。hour835では実際の食後経過は55時間だが、既存の時計は13となる。食料が必要になりそうかを判断する条件にもこの循環時計を使っているため、表示だけの問題ではない。

最初の修正案は、実際の `lastMealAt` または `hoursSinceMeal` を保存し、従来の24時間需要時計は別名の量として残すこと。初期の食後経過も初期条件として定義する。食事を取った時に実時計を更新し、経過時間に24未満の制限を置かない。需要や空腹の値を画面修正だけで消去しない。

その後、予防判断には可食備蓄、入手・帰宅・加工の見込み時間、次に必要になる食料を使う。現在の空腹は未摂食回数の粗い値で、空腹そのものによる体力低下や栄養蓄積は未実装である。栄養の物理モデルを変える場合は、表示修正と別の変更として対照を残す。

## 自宅で穀物を積み戻す理由

284回の穀物積み込みの内訳は自宅244、畑40。自宅で積んで8時間以内に同量を同じ庫へ戻す138組があり、出発や販売に至らないものを含む。B1の穀物収納183回という多さも、この反復と併せて評価する。

Fの具体例は次のとおり。

| 世界の時刻 | 状態または結果 | 記録 |
| --- | --- | --- |
| hour523 | 自宅、現金3、携帯穀物0、可食備蓄0。穀物4を積み、重量8になる | `e_019641` |
| hour524と525 | 寒さの予測により外出を見送る | Fの判断履歴 |
| hour526 | 食料を探す前の荷卸し条件に入り、同じ穀物4を同じ自宅庫へ戻す | `e_019744` |

[市場判断](../../packages/ai/food-market.ts)は所有庫に原料があれば積み込みを候補にする。一方、販売には携帯穀物が固定の播種予備4を超える必要があり、[欲求判断](../../packages/ai/anticipatory-needs.ts)は食料が不足しそうなら家に原料を戻す。積み込み、外出延期、荷卸しが別々の条件で成立し、次の目的までの見通しがないことが原因と考えられる。Fの例では、積んだ4だけでは販売にも進めない。

改善案は、物品を取る前に目的を持つこと。農作業、実際に見込む販売、加工などの目的に対し、必要量と使用先を決める。播種予備は予定する区画数と再取得の見込みから取り分ける。出発できる時間、食料の余裕、運搬時間、荷重と回復を見積もり、目的の進捗が期待できる量を選ぶ。

状態や情報が変わった場合の荷卸しは妥当な対処になり得る。反復の無条件禁止を加える案は採用候補としない。同じ状況で積み戻しが続いた経験から、目的の進捗と時間の費用を更新し、出発準備が整うまで保管を続ける案の評価を上げる。

## Fの移動失敗と経験の不足

Fの体力不足はhour805、894、966、1040、1205、1373で発生した。最初は `e_030386`。hour801に市場から自宅へ4時間の移動を始めたとき、携帯重量18、体力18、睡眠不足29。移動の基礎消費は4/時間で、世界の開始時検査には通る。

途中は冷えと睡眠不足による追加消耗があり、hour805の移動処理前に体力1となって失敗する。Fでは冷え8以上の時間末サンプルが200、睡眠不足の最大値が42。追加消耗を含めた到着までの体力を正確には予測していない。

現在の[移動予測台帳](../../packages/ai/prediction-ledger.ts)と[追跡人格](../../packages/ai/tracked-needs.ts)が対応づける主な量は完了所要時間である。体力消費の見込みは世界と共有する荷重式を使い、完了時の体力や失敗の条件を同じ予測へ結びつけて更新していない。強い体力変化を詳細経験に残す仕組みはあるが、それを運搬量や対処の学習に利用する部分が不足している。

改善案は、行動の体力消費、屋外の冷え・睡眠不足による追加消耗、休息による回復を別々の小モデルで見積もること。条件には荷重、経路、時刻、気温、冷え、睡眠不足、開始体力を含める。休憩中にも寒さと眠気は変化するため、回復量だけで出発可能と判定しない。暖かい場所へ先に移る、運搬量を減らす、その場で眠る、荷物を置くなどを、実行可能な場所と権利の範囲で比較する。

[世界の実行処理](../../packages/sim/autonomous-world.ts)はProcess実行中に身体信号を受け取っても通常の人格判断を呼ばない。CLIの移動先変更と睡眠中断は既にあるが、自律的な途中の再検討は未接続である。身体の危険信号や経路変更を判断の契機にし、世界が提供する中断・継続・途中休息の試行を本人が選べる接続を検討する。

## 採集と販売の成果を予測する

採集の失敗58件は資源がなくなった競合である。各失敗の開始から終了までの区間を照合し、58件すべてで同じ植物に対する他者の採集Eventを確認した。競合自体は局所資源の結果として妥当で、世界が各人に植物を割り当てる方式へ変えない。今の人格は現在見える熟した植物から近いものを選び、見えなければ既知の森の代表地点へ戻る。発見IDや場所の記憶はあるが、再生の見込みや採集の成功率を行先比較へ十分に使っていない。

改善案は、本人が観測した植物の場所、生育段階、観測時刻、実際の採集量、空振りを覚えること。収穫直後の場所への短い再訪は得られる量の見込みを下げ、生育期間の経験から再訪時期を見積もる。記憶した資源量は古い観測として扱い、遠方の現在量を世界から取得しない。採集量の見込み、距離、必要量、腐敗までの時間で候補を評価する。

B1の買い手待ち452判断、B2の455判断は、経過時間の数ではない。市場で成果がない時間も経験へ結びつけ、一定期間待つ案、本人の庫へ保存して別の活動をする案、後で戻る案を比較する。売れるまで立ち続ける規則を目的の固定と混同しない。観測できなかった需要は不明とし、待ったのに売れなかった経験と分ける。

パンは182製造し、129食、53腐敗。野生食品の腐敗はベリー3・果実1で、計57単位。パンの最初の腐敗例はB2の自宅、hour169の `e_006758`。売り手だけでなく、買い手の持ち運び・保管・利用の見込みも対象である。

[市場人格](../../packages/ai/food-market.ts)の固定備蓄量と新しいパンを販売する選択には、期限が十分に組み込まれていない。自食、販売、保管の対象は観測した期限が近いものから検討し、実際の売れ行きと本人の需要から製造量・購入量を更新する。比較には加工済み食品、原料を保存する案、すぐ食べられる採集物を含める。通貨26のうちSが22、Fが4を持つ最終偏在は既知の経済課題で、学習だけで市場持続が成立すると仮定しない。需要に応じた技能獲得と職選択は[既存の計画](FOOD_ECONOMY_SKILLS_PLAN.md)へ接続する。

## 穀物に依存しない経験学習

[状況別モデルの既存設計](MODULAR_PREDICTION_AND_ACTION_PLAN.md)のAからBとCへ進める。最初は少数の小モデルと既存の平均・ばらつき更新を使い、一般的な強化学習や無目的なランダム行動を前提にしない。

| 小モデル | 本人が知る入力 | 予測し実結果で更新する量 |
| --- | --- | --- |
| 移動 | 観測した経路・場所、荷重、地形を知る範囲 | 時間、到達、行動の消耗 |
| 環境による消耗 | 時刻、観測気温、場所の保温、冷え、睡眠不足 | 行動中の追加消耗と不快の経過 |
| 回復 | 場所、行為、開始体力と睡眠不足 | 休憩・睡眠の時間と回復量 |
| 入手と利用 | 観測した資源・在庫・技能・期限 | 得られる量、食料や原料の増減、使える時期 |
| 販売 | 本人が観測した提示・取引・待機 | 待ち時間、売れる量、受け取る現金 |

重量が同じ荷物の運搬経験は共有できる。食べられるか、腐敗するか、作業に必要かは物品の性質と行為で区別する。物理的な容量・権利・重量は世界が検査する。本人の時間・消耗・成果の見込みは初期信念から始め、本人に届いた経験で更新する。世界の実式を人格へそのまま渡す部分は、初期信念と実測のモデルに分離する案を検討する。

経験には次を記録する。

1. 目的、選んだ行動・必要量・予定行先、判断時の身体・荷物・利用可能な在庫と観測ID。
2. 行動前に確定した予測ID、期間、時間・体力・身体・在庫・成果の見込みと不確かさ。
3. 試行ID、受理されたProcess、実際の開始と終了、届いた結果ID、完了・失敗・中断・未観測の区別。
4. 実測と予測の差、主観モデルの更新前後、目的の進捗、費やした時間、感じた快不快の経過。

原子的な収納・購入・食事にも試行と結果の対応を使い、Processの存在を必須にしない。移動・採集・睡眠にはProcessを接続する。細かい行為の経験と、目的までの短い行動列の経験を分け、同じ成果を重複して数えない。

完了した所要時間は実際の完了結果から更新する。途中で失敗した移動は、その経過時間を完了時間として学ばず、観測した区間の消耗と到達不能の条件を更新する。予測誤差を計算する時点をそろえ、遅延や重複配送を処理し、未観測を0としない。

数値の初期更新は、既存設計の `見込み ← 見込み + 学習率 × 寄与 × (実測 − 現行の見込み)` を開始点にする。移動の距離モデルと経験モデルを同じ行動結果で比較し、ばらつきと未経験の余裕も保持する。更新頻度・係数・忘却はモデル版と記録に含める。

モデルの信頼は予測誤差から更新し、行動の評価は予測した快不快・時間・体力・成果から更新する。よく当たる危険の予測モデルも保持する。失敗して不快だったという結果から、危険な条件での大量運搬の評価を下げ、荷卸し・分割・回復を含む案の評価を見直す。

候補は、保管を続ける、少量を運ぶ、多く運んで途中で休む、先に食料を得る、などの短い行動列とする。最初の一行為を試し、新しい結果を受けて残りを再検討する。比較期間と必要な成果をそろえ、単に帰宅できたか、現金が増えたかだけで成功としない。

## 実装順と受入条件

| 順 | 変更 | 最初の対照と受入条件 |
| --- | --- | --- |
| 1 | 食事時刻の意味を修正し、目的を持った積み込みを選ぶ | 食後55時間を55と記録。利用予定のない播種予備だけを販売のために積まない。条件が変わった正当な荷卸しは可能 |
| 2 | 行動と結果の対応を体力・回復・成果へ拡張 | 同じ経路・荷重で暖かい時と寒い時、眠い時を比較。完了・失敗・中断・遅延・重複・保存再開が正しく対応 |
| 3 | 経験による見込みと候補比較を接続 | 同じ現在状態でも経験の違いで運搬量・休む場所・採集先が変わる。同重量の穀物と別の荷物で移動経験が共有される |
| 4 | 在庫・期限・販売・探索を短い目的の列へ統合 | 90日と不足対照で積み戻し、食事間隔、体力不足、採集空振り、腐敗、販売待機の変化を個別に測る |

まず順1を新規則で具体化し、順2を既存の予測台帳の拡張として設計する。旧v16は監査基準として保存し、改善版の保存則・情報境界・世界の記録再実行と人格の再計算を検査する。各指標の改善と引き換えに、初期の物品や現金を増やして結果を成立させない。

全体の評価は、合計食事数に加えて最大食事間隔、空腹と寒さの時間、疲労からの回復、無成果の反復、失敗後に同じ条件を繰り返す回数を含める。販売待機や採集競合、Cに職の仕事がないこと、休息・保管・成長待ちといった妥当な行動は、その目的と条件を併せて評価する。
