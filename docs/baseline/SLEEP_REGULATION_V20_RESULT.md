休憩・入眠待ちは体力を回復するが、実睡眠履歴へ加算しない。短い昼寝で連続覚醒が区切られてもSを初期値へ置き換えない。自然起床には不足0、十分低い眠気、30分以上の実睡眠に加えて、通常周期のSまでの回復を要求する。前日の睡眠が24時間窓に残っているだけで30分後に起こす問題を防ぐ。初期不足fixtureの高いSを回復の閾値として使わない。

世界は現在の身体信号と本人の過去の実睡眠時刻を渡し、内部S・区間の質・他人の履歴・未来の正解は渡さない。本人のSと質は推定である。眠気の結果は実行ID・対象時刻・完了状態で対応させ、開始通知だけ、未観測、外部命令による置換、中断と入眠不成立を成功した睡眠の学習にしない。初期モデルと経験補正の同じ結果に対する誤差を比べ、十分な観測があり経験側の誤差が小さい場合に補正を使う。

## 記録と実行方法

F5の **「自律: デバッグ画面（最新 v20）」** と `/?village=land-economy` はv20を表示する。旧v19は `/?village=land-economy&wood=plan`。記録選択欄からも切り替えられる。CLIの90日計測をlaunch.jsonに追加した。

```sh
npm run autonomy:village -- 90 --scenario land-sleep-regulation
npm run autonomy:village -- replay fixtures/recordings/autonomous-village-sleep-regulation-90.v2.json.gz
```

新規則IDは `autonomous-village-sleep-regulation-v20`。記録ファイルは `fixtures/recordings/autonomous-village-sleep-regulation-90.v2.json.gz`。gzipを展開した外包の `encoding` は `village-shared-state-v1`。独自ツールで読む場合は、JSON.parse後に `decodeVillageDocument<VillageRecording>(value)` を使う。画面とCLIは自動復号する。従来の非共有JSONも読める。

v19の記録は圧縮前約437MiBあり、v20の詳細な身体・判断・記憶を単一のJSON文字列へ変換するとJavaScriptの文字列上限に達した。共有保存は記憶や判断を削除せず、反復するJSON部分を参照表へまとめる。旧ファイルとハッシュは変換しない。表示用の読み取り専用復号は同じ部分を共有でき、実行へ渡す応答と世界の復元では可変部分を独立に展開する。

### 旧v19との比較と未達

旧v19は全員合計90食・最終空腹0、最長食事間隔25〜33時間。v20はS87・C85食で、最長93・112時間となった。食事を維持する目標は達成していない。睡眠の身体規則の成立を、90日経済の成立へ読み替えない。

空腹3以上の判断を監査すると、S165件のうち探索66、製パン原料の待機26があり、C232件のうち探索101、安全な取得時間の待機54がある。睡眠に置き換えただけで取得を先送りする優先順位は修正したが、枯渇・再生する植物の探索と市場原料の待機を含む行程の見込みが不十分。資源を増やしたり必要睡眠を減らしたりして成立扱いにせず、次に探索先・見込む収量・再確認の時刻、取得／加工／睡眠の行程を検討する。

## 検証と境界

新規対照23/23、旧v19/v12の対照と旧v19の90日再実行、対象ブラウザ3/3（新v20の実時刻・巻き戻し、旧v19/v18比較、旧v15所持品・身体）、型検査を含む本番ビルド、コンテンツ・文書リンク・差分検査が成功。今回の全体テストは実行していない。

- 身体の対照：通常6睡眠／18覚醒を90周期、不足0。覚醒20／24時間で不足2／6時間、昼夜・疲労、休憩と睡眠、短い昼寝、2時間の入眠不成立、睡眠の質と寒さの中断、日付境界、履歴の破損を検証した。
- 世界・本人：入眠待ち／実睡眠の保存再開、15分の予約、起床命令、冷え中断、私的なSや他人の履歴を渡さない観察、開始と完了の結果照合、対応しない結果の除外を検証した。10日の全判断再計算と保存再開・共有記録再実行、その後の通常人格による継続も一致した。
- 90日：共有記録から同じ観測・応答で世界を再実行し、最終状態・Event、通貨と身体・食料の保存則が一致した。旧v19の90日再実行も最終状態まで一致した。

身体は15分、行動判断・作業・気温・空腹の更新は現行の1時間境界を維持する。移動の5/15/30/60分表示は補間であり、身体の解像度を変えない。睡眠段階・長期認知負債・個人差・筋損傷・一般の避難場所は未実装。本人の睡眠予測は初期係数と条件別の小さい誤差補正で、任意の環境・未知の身体係数を同定する学習器ではない。快不快による汎用の行動価値学習、技能獲得・職選択、経済持続Dは後続とする。
