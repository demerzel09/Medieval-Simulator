# 移動の事前予測と実結果の対応 v13

> 資料区分：旧版・旧段階の実験記録／計画。本文の「現行」「最新」「次の作業」は記載時点のもの。現在の実装は [STATUS](../STATUS.md)、今回の作業は [NEXT_SESSION](../NEXT_SESSION.md) で確認する。

更新: 2026-10-02。[小モデルの設計](MODULAR_PREDICTION_AND_ACTION_PLAN.md)の**段階A**を実装した。新しいCLIシナリオは `land-predictions`、規則版は `autonomous-village-prediction-ledger-v13`。画面の標準は引き続きv12。複数モデルの競合・切替と快・不快による行動評価の学習は未実装。

## 実装したこと

- 移動前に人物別の予測ID、開始時点・場所、目的地、荷物の量、所要時間の見込み、ばらつき、経験数、根拠の観測IDを保存する。結果を見てから見込みを書き換えない。
- 世界が試行を受理すると、本人へ実行ID・試行Event ID・開始時刻・目的地を届ける。本人に世界の計算した予定所要時間を渡さない。
- 完了結果が本人へ届いた際、予測と実行ID・対象・期間を照合する。実際の終了時刻から所要時間を計算し、配送遅延や次の判断までの待機を移動時間に加えない。
- 完了した実測を既存の移動時間の平均・ばらつきへ一度だけ反映する。現在地が目的地になったことだけでは学習しない。
- 拒否・実行失敗・目的地変更・外部Commandによる提案の置換・未観測を区別し、完了所要時間や誤差0として集計しない。途中で目的地が変わった移動の残りは、元の予測へ結びつけない。
- 目的地の座標は現地観察、自宅の既知情報、本人の過去の観察から得る。座標も経験もない行先は所要時間を未推定とし、完了実測を記憶しても事前予測誤差を捏造しない。
- 未決予測は最大16件、直近の結果は24件。未決の期限は48時間または見込みの4倍＋8時間の大きい方。届いた結果を先に処理し、残った期限超過を未観測として閉じる。累計の件数・絶対誤差・符号付き誤差・二乗誤差は保持する。

`packages/ai/prediction-ledger.ts` が照合・期限・集計・保存検証を、`packages/ai/tracked-needs.ts` が既存人格との接続を扱う。v12の行動優先順と身体・食品の物理法則は継承する。v13では移動経験の更新を照合された完了結果へ置き換えたため、配送や途中変更がある条件で判断が変わり得る。

## 再現と履歴

```bash
npm run autonomy:village -- 90 --scenario land-predictions
npm run autonomy:village -- replay fixtures/recordings/autonomous-village-predictions-90.v2.json.gz
npm run autonomy:village -- history fixtures/recordings/autonomous-village-predictions-90.v2.json.gz B1 /tmp/prediction-history-B1.json
```

CLIは人物ごとに予測・完了・除外・誤差を比較できた件数と誤差合計を表示する。人物履歴の判断応答 `response.subjectiveUpdate.anticipation.predictions` に、事前予測とその結果がある。詳細な全履歴は各判断の記録から確認でき、人物の有限な記憶と区別する。

旧v12とそれ以前の同梱記録は、元のfixture・規則版で再実行する。新しい世界側の結果情報は `predictionLedger` を有効にしたfixtureだけに追加する。保存応答による世界の再実行に加え、7日対照では記録した各入力から人格応答を再計算し、記録との一致も検査する。

## 90日の実測

単一seed `240924`、v12と同じ場所・身体・食品条件。[同梱記録](../../fixtures/recordings/autonomous-village-predictions-90.v2.json.gz)。

| 項目 | 結果 |
| --- | --- |
| 全員・各日1食 | 450食。パン270、ベリー122、野草58。直接穀物0 |
| 移動の事前記録／完了照合 | 977／977件 |
| 事前の時間見込みと実測を比較 | 975件。SとCの最初の未知行先各1件は比較対象外 |
| 絶対誤差合計／符号付き誤差合計 | 8時間／−8時間 |
| 移動の除外・未観測・末日の未決 | 各0件 |
| 拒否／Process失敗 | 拒否0、植物の採集競合による失敗4。移動失敗0 |
| 人格判断／世界Event | 7,141／41,498件 |
| 最終状態ハッシュ／Eventハッシュ | `75d1ed7d`／`64a365b8` |

人物別の完了照合は S158、F207、C208、B1/B2各202件。移動時間の経験数の合計と完了件数が一致することを検査する。この固定地図・ほぼ一定の所要時間・時間単位の計測で小さい誤差だったことを、変化する道路や未知地形への予測精度の証拠とはしない。食品売買は引き続き成立していないため、加工経済の持続性を達成したとは扱わない。

## 検証と残る範囲

対象テストは配送遅延、重複、別Process・対象・期間の不一致、期限、未知行先、保存検証、現在地だけでの誤学習防止を検査する。実際の世界を使って受理・完了・拒否・途中失敗・目的地変更・外部Command置換・保存再開を検査し、7日の人格再計算と世界再実行、新90日記録の再実行と毎日の食事を確認する。最終的な検証件数は[STATUS](../STATUS.md)へ記載する。

圧縮記録は20,926,566バイト（約20MiB）、展開後は314,938,964バイト（約315MB）。既存の判断前後の全文スナップショットへ直近の予測結果が加わるため、v12より大きい。モデル競合を拡張する際は、主観履歴の差分・参照による保存を別途設計する。

次は段階Bとして、同じ移動結果を予測する初期距離モデルと経験モデルを同時に記録・比較する。荷重・出発条件で経験を分け、一回の例外と持続する迂回を区別して寄与と見込みを更新する。その後に寒さ・睡眠へ広げ、段階Cの快・不快による行動評価と短い行動列へ接続する。
