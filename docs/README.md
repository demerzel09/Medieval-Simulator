# 文書の入口

更新: 2026-10-24。**設計の本文は次の2本を正本とする。** 旧実装の構成から離れ、資源を管理する世界と人物、共通の法則、具体的な作用過程から大構造を定める。

| 正本 | 役割 |
|---|---|
| [RESEARCH：設計思想の背景調査](RESEARCH.md) | 前回の設計が止まった理由。REA・DDD・関連経済理論・存在論と実装例。確認した事実、こちらの推論、採用範囲と限界 |
| [DESIGN：設計原則](DESIGN.md) | 元々の目的。六つの部品と一周の動きからなる大きな構造。P01〜P12の制約、責任表、違反例。末尾の食事経路の照合は細部で、骨格が動くまで増やさない |

背景から検討するときはRESEARCH→DESIGN。再開時は従来の指定どおり **NEXT_SESSION→STATUS→DESIGN→DECISIONS** の順で確認し、根拠が必要な箇所のRESEARCHを追加する。全文書を一括で読まない。

| 補助文書 | 残す内容 |
|---|---|
| [NEXT_SESSION](NEXT_SESSION.md) | 最新の依頼、次の一作業、読む範囲、環境と許可 |
| [STATUS](STATUS.md) | 今回行ったこと、現行実装の事実、検証と未実行 |
| [DECISIONS](DECISIONS.md) | 旧版の採用判断を探す入口。新原則の並行した正本にはしない |

## 既存文書の保存と再利用

| 対象 | 今回の扱い | 今後読む条件 |
|---|---|---|
| 再編前の入口・引き継ぎ・状態・設計・判断 | 5本の全文を[2026-10-24の保存版](archive/README.md#reset-2026-10-24)へ退避。相対リンクを補正 | 以前の方針・検証・具体的な互換条件を調べる場合 |
| [foundations](foundations/README.md)の旧詳細設計・研究・企画 | **パスを維持した参照アーカイブ**。各文書冒頭に扱いを明記 | 新原則への適合を確かめ、必要な知見や実装を再利用する場合 |
| [baseline](baseline/README.md)の実測・監査・旧計画 | 実測本文と版別記録を保持。旧計画は当時の案として扱う | 対象版の再現、法則の意味、比較条件、過去の失敗を調べる場合 |
| [archive](archive/README.md)の既存履歴 | 履歴として保持 | 当時の変更理由を調べる場合 |

過去の成果を削除するのではなく、**現在の規範・作業指示から外す**。移動で参照を壊すより、旧資料の役割を明示して必要時だけ読む。旧本文中の「正本」「最新」「次」は記載時点の意味であり、現在への指示ではない。旧契約の全条項を新設計へ自動継承しない。

再利用は、対象資源、守る法則、状態の管理・更新責任、作用と結果、知識の到達、旧版との比較条件を照合して判断する。新しい原則と衝突する構成は置換・統合・削除できる。法則・既存記録の解釈と比較可能性は保つ。

## 増やさないための更新規則

調査はRESEARCH、原則はDESIGNへ統合する。STATUSとNEXT_SESSIONには短い現在情報だけを残す。細かな経過は必要な版別結果へ記し、入口へ積み重ねない。新しい文書は、この2本では表せない役割が必要になったときに限る。旧資料の物理的な移動・削除は、参照と再現手段を確認してから行う。
