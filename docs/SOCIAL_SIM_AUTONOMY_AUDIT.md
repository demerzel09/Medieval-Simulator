# A3に向けた社会シム・自律性の監査

状態: 2026-09-26、`83c73e4`のA2独立20人・3日fixtureを読んで確認した課題。A3の90日経済はまだ存在しない。この文書は受入結果でも実装方針の確定でもない。現行90日ゲームの1,000人経済と、このA2 fixtureの結果を混同しない。

## 現在できていること

買物係、売り手、農民、運搬人は共通の`PersonalityModel`境界を経て行動を試みる。各モデルを止める対照では、それぞれ注文、補充、収穫、配送が止まり、simは現物・通貨・所有権・容量・位置・体力を検証する。したがって人物の行動は単なる表示ではない。ただし「各職務の行動を止められること」と「社会が自律的に維持・再編すること」は別の受入条件である。

空腹については、H0の40通貨を準備金へ移す既存Commandを使い、A2を3日進める読取用の対照を実行した。H0の5人は1/2/3日目に全員`hunger=1/2/3`となったが、各日末の体力は全員100へ回復した。F0/F1を含む農民の収穫は基準どおり21/21/18食、協同事業には90通貨が移り、市場には15食が残った。したがって「空腹にならない」は厳密には違い、**空腹値は増えるが実害と適応行動がない**。これは一つの決定的な対照であり、疾病や長期生存の計測ではない。

## A3で自律性を判定するための対照

1. **所得と権利の閉路:** 誰がどの条件で働き、誰の財を作り、売上のどの既存通貨を賃金・運賃・持分として受け取るかを人物/事業の行為Eventで追う。初期資金の取り崩しが尽きても、日31〜90に実働・購入・食事が続くこと。支払不能と未払は隠さない。
2. **身体の反事実:** 食料不足が回復・作業量・判断に実際の差を生むこと。最小段階では空腹、睡眠負債、仕事由来の疲労を別の状態として扱い、同じ条件で食事/睡眠だけを変えた対照を作る。病気や複数のストレス値は、この因果関係と回復経路を確認してから増やす。徹夜は選べてよいが無料にはしない。
3. **移動の進行中状態:** 人と荷車の作業量・体力・摩耗を単位時間または実際に進んだ距離から積算し、道中で止めたときは未走行分を請求しない。距離2倍、途中の遅延、荷の軽重を独立に変える。
4. **構造変更:** 描画矩形ではなくsim上の道路距離と所要時間を変える。家・畑・市場の配置、世帯人数、役割人数、荷車数を変えても、保存・所有権・容量・時間の不変条件が保たれること。必ずしも全条件で経済が安定する必要はないが、失敗も本人の判断・情報不足・現物不足として説明できること。単一の固定IDを変えただけでプログラムが壊れるなら不合格。
5. **中央制御の監査:** 各人物モデルを一人ずつ止め、作業と下流の在庫・収入・食事が変わること。欠員時に別人が補う場合は、その人の認識、引受、移動、仕事、対価、因果Eventを示す。`phase`は時刻と物理的な結果の配送へ縮小し、制度の当番表/市場枠もデータと実在人物の運用へ寄せる。
6. **継続性と規模:** 複数seedで90日を保存再開・Command再実行し、後半の日別・世帯別の貨幣、食料、空腹、労働、体力、車両状態、未払を観測する。性能は別途実測する。3日fixtureや既存90日ゲームの成功をA3の合格として流用しない。

最初に閉じるべきなのは、貨幣が世帯へ戻り、その所得と実際の食事が翌日の労働を支える循環である。その時点で職業の動機と身体の最低限の帰結を結び、次に道中の時間積算と地理・人口を変える対照で「固定脚本による見かけの安定」を見分ける。[既存ロードマップ](AUTONOMOUS_SANDBOX_ROADMAP.md)のA3受入条件も、この監査結果で具体化する。
