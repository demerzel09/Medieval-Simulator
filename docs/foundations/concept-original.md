## 1. 合理的な行動が難しいストラテジー

```text
Total Warのようなストラテジーをつくりたい。一般的にプレイヤーは基本的に合理的な判断を行うことを強いられる。これは、歴史の流れで考えると、確かに、特定の英雄、例えば始皇帝や、チンギスハーンや、曹操などがやったかもしれないが、一般的には、そういうことは群雄の中でも非常にまれであり、一般的には個人の欲求が優先される。これは勝つためには必ずしも優先すべきではないが、多くの群雄はそうではない。
古代の通信がネックになる大規模な軍隊においては、最初に戦場の設定の時点で勝ち負けが決まっていることが多く、それをメタ的に把握し制御できたものが勝つが、これは非常に難しく、ほとんどが稀にしか制御できる人はいない。
であるにもかかわらずストラテジーゲームのプレイヤーはほとんど、非常に合理的な行動を目指す。
作りたいストラテジーゲームは、非常に合理的な行動をとることが難しく、自然と合理的でない人間の欲望が優先されるようにプレイヤーが判断したくなるゲームだ。　つまり合理的な行動をとることは不可能ではないが、非常に苦痛や困難を伴うものであるゲーム。それを含めたメタ的に一部合理的に行動することで、勝者となれるというようなもの。実は、先ほどの成功した英雄もそうだったであろうと思うのだ。すべてがすべて合理的な行動をとるのは、彼らであっても簡単ではなく、人々の指示は得られなかったはずなのだ。これをデザインにいれたい。
これをデザインに入れるにはどうすればよいだろうか？アイディアを上げてほしい。
```

## 2. 一人ひとりを持つ国家

```text
兵士、住民一人ひとりにまで、パラメータを持たせるということは可能でしょうか？もちろん、君主、領主、将軍、部隊長、兵士、有力商人、有力地主、一般市民などのレベルに応じて、与える影響は下に行くほど小さくなると思いますが。しかし、精々一つの国家を最大1万人、軍も1000人ぐらいがマックスにすれば可能な気はします。身分があり、文化によるバイアスもある。各自の仕事や性格もあり、経済と国家を回す。これを実際にやっているゲームはあるでしょうか？
```

## 3. 文化、約束、大義、革命

```text
遠征のための徴税 → 村の不満 → 徴募兵の士気低下 → 隊長の命令への反応 → 会戦の結果  
これですが、理由もなくとられると不満になりますが、徴募兵への、遠征の報酬の約束や、報酬が定義、あるいは文化として定義されるなら、デザインでとりこめるといいですね。文化が違う人間が同じ条件で、合理的な判断ができると、ゲームの面白さをなくすし、逆に言うと、革命を起こすことができる場合、ある特定の定義（大義）を、特定の人間の集団に訴えて、支持される状況になれば成立する。そこまでのフレキシブルさを、個人単位で成立させられるほど、高度な個人をシミュレートできるかというとかなり難しそうですが、制作時にLLMを使って、パターンを作ることができれば可能かもしれないですね。
```

## 4. 少数の柔軟な個人

```text
特定の個人だけ、特定のパターンに縛られずフレキシブルに一貫性のある意思を持って動くのも楽しそうです。計算が可能な範囲でごく少数に混ぜたいですね。
```
