# 個人を経由する経済の独立実験

2026-09-27。従来のA3は固定配置の20人・協同事業を保つ回帰実験とし、共同口座や世帯への自動配分がなくても成立する最小の因果を二つの独立世界で調べる。どちらも90日ゲームへは未接続で、社会全体の完成形ではない。

## 採集生活 `individual_life`

`packages/sim/individual-life.ts` は場所・人物・身体状態・自然資源・個人の袋だけを持つ。世帯、市場、農場という制度的な実行主体はない。人は `packages/ai/individual-life.ts` の `LifeModel` を通じて、現在地の資源、空腹、体力、所持食料、知っている採集地から一つの行動と次の起床時刻を返す。世界側はその試行を `PhysicalState` で検証して確定し、採集、食事、休息、出発、到着を原因付きEventにする。採った食料は本人所有であり、他人が勝手に持ち出す試行は失敗する。

標準fixtureは3人、2地点、毎日3食再生する資源。`npm run autonomy:life -- 90` では累計270食採集・270食消費、90日末に3人とも空腹0となった。全員が行動しないモデルに替えると採集・食事は0で空腹が増える。資源1食を2人で競うと1人の空腹が残る。人物IDと資源位置を変更したfixture、空の採集地から別の採集地への移動でも動く。これは固定再生量を前提とする小対照で、資源生態や死亡・疾病の検証ではない。

## S個人の市場 `individual_market`

`packages/sim/individual-market.ts` では `market` はS所有の**場所**、商品置場はS所有の物体である。木立の資源を採った時点で食料はFのもの。Sは自分の財布の仕入れ金をCに託し、Cに運賃を払う。Cが現地でFから買うと、食料の所有権はF→S、通貨の所有権はS→Fへ移る。CはS所有の食料を運んで置場へ入れる。B1/B2が買うと食料はS→買主、通貨は買主→Sへ動く。場所自体は販売・分配・送金を実行しない。

`packages/ai/individual-market.ts` は同じ `PersonalityModel` 入出力境界から、S・F・C・買主の局所的な提案を返す。Sは前日に資金を持つ客が品切れに遭った観測なら売値を上げ、売れ残りなら下げる。見込み利益と手元資金から翌日の仕入れを決める。Cは提示運賃で受諾し、Fは提示された仕入値で売る。この実験での「需要」は実際に支払能力を持つ客の品切れ、「供給過剰」はSの売れ残りとして観測する。市場全体の真実をSへ渡してはいない。

標準fixtureの初日はSが1通貨で1食仕入れ、Cに2通貨を払い、4通貨で1食売る。Sの現金は10→11、Fは0→1、Cは0→2となり、Sの実現損益は+1。翌日は品切れを見て4→5へ値上げする。その後、買主の資金が尽き、売れ残りに応じて値下げする。`npm run autonomy:market -- 90` の90日目は累計販売5食、S現金17、F現金5、C現金8、買主2人の現金0。価格は1まで下がるが、買主の所得源がないため販売が止まる。**Sの利益と資産保存は確認できたが、閉じた社会経済の安定は失敗**という結果である。買主は購入した食料をまだ消費せず、F/C/Sも空腹や体力を持たない。この市場fixtureは取引の対照に限る。

## 境界・観察・残る課題

- 物体の `parentId` は所在、`ownerId` は所有者。通貨・食料の数量と所有を別々に検査する。食料や通貨の移動は原子的な `physicalTransaction` で行う。
- 人格モデルは行動を提案するだけで、物体の書換権は持たない。`PersonalityModel` はルール実装を後で交換できる外側の契約である。ただし `individual_market` は役割ごとの `phase` を中央スケジューラが順に呼び出す。F/C/S/買主が自らの起床時刻と届いた情報だけで仕事を連結する段階にはまだ達していない。
- 現金をCに預ける権限とF/Sとの売買合意は現在、取引を呼ぶコードが `ownerIds` に渡す。約束・委託状・対面同意を検証可能な権限物体/Eventとして一般化する必要がある。
- 採集生活では `knownResourceSites` が地図上の全資源所在地から作られ、実際の学習や噂の伝播ではない。複数の枯れた採集地を回る際の記憶は「その日失敗した一地点」まで。地図をさらに広げて測る前に、人物ごとの知識と探索を設ける。
- 新しい二世界は保存・読込・同一seed再実行で同一結果になる。現在乱数は使わず、seedは記録だけ。外部Commandの保存と再適用は未実装で、旧M0〜M3のCommand契約とは別の実験である。
- 採集行動と移動の体力費は行動時の固定費。荷の重量・距離・単位時間の仕事から力学的に積算する共通過程、道中トラブル、車両修理は未接続。
- 画面 `/?individual=life`、`/?individual=market` は各日末1〜7日の場所・人物・所有・現金・食料・行動Eventを表示する。道中の途中位置と1日の時刻別再生はまだない。CLIは90日まで計測できる。

次の実装は、個人市場を身体と生活行動のある同一世界へ接続し、買主の仕事/所得と食料消費を導入する。その後、契約・配送・売買を各人の起床と情報到達で起動し、地理と人員を変えた対照および故障・不作に進む。固定A3の資金循環を移植する際も共同口座を再導入せず、人の労働・所有・移転Eventを通す。
