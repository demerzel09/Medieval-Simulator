# 実装状態（2026-09-25）

## 現在地

M0→M1→M2の機構受入を通過。M3の90日ゲームとUIは実装済み。M3の正式完了には設計18.5の人間試遊（3〜5人×30〜60分）が残る。これを自動テストで代替したとは扱わない。

今回の追加：初期宮廷に各国1人の書記と3人の伝令を既存住民として配置。面談の呼び出しは書記による準備、伝令の配送、対象者の判断と同行移動、到着後の面談で成立する。「訪問」も選択可能。全1,000人の日次活動と個別Eventを開発モードで検索できる。通常画面は君主の認識に基づく表示を維持。

動機・行動・社会的約束を一般化する研究と設計候補は [RESEARCH_MOTIVATION_ACTION.md](RESEARCH_MOTIVATION_ACTION.md) に記録した。A〜Cの比較は引き続き検討稿として保持する。

A〜Cに共通するv1の交換境界と内部ポートは [AGENT_INTERFACES_v1.md](AGENT_INTERFACES_v1.md) に定義した。`DecisionRequest/Response`、人物の認識と世界の真実、動機・意図・Task・対人約束・行動・Eventの分離を設計契約とする。**文書設計のみ完了**し、型の実装、既存コード・セーブの移行、契約テスト、ルールAIでの再検証は未着手。現行M0〜M3の挙動を変更していない。

判断器の共通入口も同文書の第4章に追記した。段階別の一問、関連する個人認識と静的カタログの投影、共通 `ChoiceDraft`、ルール内の動機別影響評価、NN/LLM/人間の変換境界を定義。文化・仕事・役割・世界構造を入力として一般化する設計であり、**各アダプターの実装や性能測定は未実施**。

個人の期待は認識データとして設計したが、予測器は任意のモデル内部部品とした。単純な市民ルールも、高度な予測を使うモデルも同じ判断契約を使う。期待を変えるのは本人が結果を知覚した後である。この区別も文書設計のみで、予測・期待更新のコードと契約テストは未実装。

## 簡略化・未実装

- 民間経済は国ごとの共同事業口座。個別雇用主/店舗、木材・装備の一般市場、手数料、未払賃金の後日返済は未実装。民間賃金2の判断はDECISIONS参照。
- 文化は3規範の優先傾向＋個人差。価値4軸、君主への信用と家族世帯を中心とする最小モデル。汎用規範DSL、8価値軸すべて、疎な社会関係グラフ、文化学習は未実装。
- 約束は金銭報酬・家族扶助・戦利品が中心。融資契約の元本実行、合意再交渉、権利/役職/減税のPromise履行判定は未実装。
- 外交は有料商用通行と不可侵の評価。捕虜交換、任意の物資条項、軍用通行交渉、不可侵違反の制度的処理は未実装。
- 戦場は部隊単位の移動/戦力計算、個人の損害/士気。個別物理衝突、側背面判定、プレイヤーによる自由布陣、医療/負傷回復、装備回収、部隊との合流追跡は未実装。欠食は士気・反応に作用するが飢餓死は未実装。
- 退却敗軍の戦略帰還と輸送失敗時の返送は簡略化。将軍が複数部隊を指揮できるため、独立した隊長階層は今後分離する。
- 通常UIは君主のObservationのみで、住民一覧は検索＋先頭60件。開発モードは全員を80人ずつ表示し、選んだ人物の活動・個別Eventを全期間閲覧する。Eventグラフの視覚化は未実装。
- 伝令は道の所要時間・一人一便の予約・不在による未達を扱うが、道中の襲撃や中間座標、相手不在時の自動再送は未実装。0.1.0セーブの進行中便は以前の到着時刻を維持する簡易移行。
- 敵の通常AIは補充・峠の守備・通行交渉が中心。他領への機会的な侵攻、占領後の高度な奪回戦略は未実装。
- 政治運動/反乱はM4。LLM実接続、出生/継承、3D、公開デプロイは行っていない。Planner境界とMockのみ。
- 大規模性能とブラウザfps/入力応答p95は未計測。M6のworld-30000ベンチ指定は未対応として明示的に失敗する。

## 再開手順

1. DESIGN/DECISIONS/本ファイルを読み、`npm ci`、`npm run typecheck`、`npm test`。
2. `npm run dev` で遊び、`artifacts/sample-day3.json` / `sample-war-day4.json` をJSON入力から読み込む。
3. 人間試遊は `docs/PLAYTEST.md` を使用して実施し、実際の結果を記入。
4. 動機・行動の共通化は [v1インターフェース](AGENT_INTERFACES_v1.md) の受入テストを先に準備し、Aの実行境界から段階移行する。各段で既存90日ゲームの受入条件を保つ。Bの動機・意図・社会的約束を接続した後、Cの判断アダプターを試す。
5. 未実装のM1〜M3詳細を上記から優先し、人間試遊で出た問題を修正してからM4を検討する。
