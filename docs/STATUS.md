## 自律経済の実測

最優先の「全員が本人に届いた情報から自律的に行動し、世界が環境変化と試行結果だけを確定する一つのシステム」は**未実装**。`individual_life` は3人の生活判断、`living` はB1/B2の判断と現物支払を部分的に試す。前者にも固定の資源知識があり、後者はS/C/F/Bの中央phaseを残す。`packages/sim/physical.ts` は物体木・容量・所有の操作境界であり、身体・資源・仕事・情報・制度を統合した世界法則ではない。

| 実験 | 実測・判定 | 主な限界 |
|---|---|---|
| A3固定20人経済 | 基準seedの90日で生産/食事各1,800、販売360件、日31〜90の欠食0。単回約107秒 | 固定地理・協同事業・単一seed。全員の自律は未受入 |
| `individual_life` | 3人・90日で採集/食事各270、末日空腹0 | 固定資源再生。市場・所得なし |
| `individual_market` 取引のみ | 90日で収穫5、販売4、腐敗5。S/F/C/B1/B2現金16/5/8/1/0 | 買主の所得なし。取引停止。食事なし |
| `individual_market` `living` | 90日でベリー収穫10、販売/食事9、腐敗1。薪採集/燃焼9、B1/B2の薪所得10/8。現金S/F/C/B1/B2は20/10/14/4/2、B空腹85/86 | **安定未達**。仕事も食料販売も早期停止。F/C/Sは食事しない |

生活市場はB1/B2本人所有の家・備蓄箱・食品ロットを使う。Bが薪の納品を提案し、Sが売場を開くために必要な薪を受諾し、Bの採集・物理納品後にSが自己資金で払う。拒否、未作業、未納品では払わない。買物・保管・食事も本人提案で、現物/現金/腐敗はsimが確定する。S/F/Cの仕事は中央phaseで呼び出す。詳細は[生活市場](baseline/LIVING_MARKET_EXPERIMENT.md)と[個人経済の実装](baseline/INDIVIDUAL_ECONOMY_IMPLEMENTATION.md)。

## 検証結果

薪仕事の追加後（2026-09-27）は `npm test` **16ファイル110/110成功**、`npm run typecheck` と `npm run content:validate` 成功、`npm run test:browser` **12/12成功**（本番ビルドを含む）。90日CLI実験でも物量・通貨保存、保存再開と同seed再実行を確認した。生活市場の性能は**未計測**。既存のA3計測は固定配置・単一seedだけ。M6の30,000人・大規模会戦・ブラウザfpsは未受入。

## 次に必要な実装

1. 小世界の中央phaseを人物ごとの起床・情報到達・試行に置き換え、世界は環境の変化と試行結果だけを確定する一つの実行ループを作る。旅の距離/荷重/体力の時間積算と、契約証拠から物理権限への導出も未実装。
2. F/C/Sを買主と同じ身体・食事・備蓄系へつなぎ、資金と食品の90日対照を再測定する。Bの薪仕事だけでは空腹を解消できていない。
3. Sの売場燃料以外にも、人物が実際に必要とする仕事・財と需要情報の到達を増やし、地理・人数・供給を変えた反事実で自律性と破綻を測る。

本編M3の人間試遊は[記録票](baseline/PLAYTEST.md)で別途実施するが、当面の設計・実装の優先度は下げる。

起動: `npm run dev` の `/?individual=living`、CLIは `npm run autonomy:living -- 30`（最大90日）。他のモードと操作は[readme](../readme.md)。変更後は対応テストと保存/再実行・保存則の対照を実行し、結果を本ファイルへ更新する。
