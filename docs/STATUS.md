## 自律経済の実測

最優先の「全員が本人に届いた情報から自律的に行動し、世界が環境変化と試行結果だけを確定する一つのシステム」は、5人の独立した `autonomous_village` 版1で90日受入を満たした。単一地理・rule人格・正常初期条件での成立であり、任意の人格や人口に対する一般性は未検証。旧 `living` の中央phaseと不安定な結果はそのまま回帰用に残る。[実測と対照](baseline/AUTONOMOUS_VILLAGE_RESULT.md)。

版2では[記録・経路・土地](baseline/VILLAGE_RECORDING_AND_LAND_V2.md)を追加した。人物ごとの判断入力/応答/結果をJSONへ保存し、記録された応答からGatewayを再実行して状態・Eventを照合できる。CLIで別条件の記録の最初の差分を比較する。移動は矩形グリッドA*の歩進捗、通行止め時の再探索、途中の行き先変更を持つ。穀物の耕作/播種/72時間成長/収穫、果樹・野草・草の再生、ウサギの移動/摂食/成長を土地セルに置いた。通常の90日交易は引き続き野生ベリーの循環であり、穀物中心の90日生活は未受入。
版2の正常90日も5人全員が毎日食事・薪使用を継続し、食料・薪各450採集/消費、通貨26を保存した。Eventは26,638件、記録JSONは約12 MB、[同梱の圧縮記録](../fixtures/recordings/autonomous-village-90.v2.json.gz)は約0.8 MB。記録からの90日再実行で状態・Eventが一致した。画面は追加していない。

## 検証結果

`autonomous_village` 追加後（2026-09-27）は `npm test -- --testTimeout 15000` **19ファイル127/127成功**、`npm run typecheck`、`npm run content:validate`、`npm run build`、90日CLI成功。通常の `npm test` は旧M3の1件が並列時の既定5秒制限を超えたため、制限を15秒として全体回帰を確認した。新しい9件のテストに、90日各日、拒否・欠員、資金・資源・容量・通知不足、未到達情報、重複配送、契約外支払、部分納品、競合資源、途中保存と同Command再実行を含む。今回ブラウザテストは実施していない。以前のブラウザテスト12/12成功は生活市場追加後の結果。生活市場の性能は**未計測**。既存のA3計測は固定配置・単一seedだけ。M6の30,000人・大規模会戦・ブラウザfpsは未受入。
版2追加後の最終検証は `npm test -- --testTimeout 15000` **21ファイル134/134成功**、`npm run typecheck`、`npm run content:validate`、`npm run build`、通常90日CLIと90日記録再実行が成功。旧M3の1件が並列実行時の既定5秒制限を超えた過去の結果があるため、全体回帰には15秒制限を使った。版2の7件はA*経路/地形/途中変更、記録再実行/差分、穀物・果樹・野草・ウサギ、技能/場所の拒否と保存再開を検査した。今回は画面を変更しておらず、ブラウザテストは実施していない。以前のブラウザテスト12/12成功は生活市場追加後の結果。生活市場の性能は**未計測**。既存のA3計測は固定配置・単一seedだけ。M6の30,000人・大規模会戦・ブラウザfpsは未受入。

## 次に必要な実装

実装順と90日の受入条件は[自律する90日生活世界への実装計画](baseline/AUTONOMOUS_90_DAY_PLAN.md)を正本とする。
段階0の[実行可能性表](baseline/AUTONOMOUS_90_DAY_FEASIBILITY.md)と、実行fixtureによる段階1〜4の[90日受入](baseline/AUTONOMOUS_VILLAGE_RESULT.md)は完了。実行では初期通貨26、初期体力16・上限20を使用した。版2の記録・経路・土地を基に、地理・技能・人数・価格・人格方式を変えた際の一般化を検証する。

1. 畑作の食料で5人の90日交易を成立させるための、土地面積・作付け/収穫時期・労働時間・資金の収支表と対照を作る。
2. 複数作物、季節、動物の繁殖・死亡、道路の複数人競合へ局所法則を広げる。まず版2の保存・再実行と物量保存を維持する。
3. 版1の注文専用権限を、複数の契約・部分履行・返金・期限に使える証拠形式へ一般化し、人格や人数を変えた90日対照を追加する。

本編M3の人間試遊は[記録票](baseline/PLAYTEST.md)で別途実施するが、当面の設計・実装の優先度は下げる。

起動: `npm run dev` の `/?individual=living`、CLIは `npm run autonomy:living -- 30`（最大90日）。他のモードと操作は[readme](../readme.md)。変更後は対応テストと保存/再実行・保存則の対照を実行し、結果を本ファイルへ更新する。
