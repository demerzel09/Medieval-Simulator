## 簡略化・未実装

- 民間経済は国ごとの共同事業口座。個別雇用主/店舗、木材・装備の一般市場、手数料、未払賃金の後日返済は未実装。民間賃金2の判断はDECISIONS参照。
- 文化は3規範の優先傾向＋個人差。価値4軸、君主への信用と家族世帯を中心とする最小モデル。汎用規範DSL、8価値軸すべて、疎な社会関係グラフ、文化学習は未実装。
- 約束は金銭報酬・家族扶助・戦利品が中心。融資契約の元本実行、合意再交渉、権利/役職/減税のPromise履行判定は未実装。
- 外交は有料商用通行と不可侵の評価。捕虜交換、任意の物資条項、軍用通行交渉、不可侵違反の制度的処理は未実装。
- 戦場は部隊単位の移動/戦力計算、個人の損害/士気。個別物理衝突、側背面判定、プレイヤーによる自由布陣、医療/負傷回復、装備回収、部隊との合流追跡は未実装。欠食は士気・反応に作用するが飢餓死は未実装。
- 退却敗軍の戦略帰還と輸送失敗時の返送は簡略化。将軍が複数部隊を指揮できるため、独立した隊長階層は今後分離する。
- 通常UIは君主のObservationのみで、住民一覧は検索＋先頭60件。開発モードは全員を80人ずつ表示し、選んだ人物の活動・個別Eventを全期間閲覧する。Eventグラフの視覚化は未実装。
- 伝令は道の所要時間・一人一便の予約・不在による未達を扱うが、道中の襲撃や中間座標、相手不在時の自動再送は未実装。0.1.0セーブの進行中便は以前の到着時刻を維持する簡易移行。
- 敵の通常AIは補充・峠の守備・通行交渉が中心。他領への機会的な侵攻、占領後の高度な奪回戦略は未実装。
- 政治運動/反乱はM4。LLM実接続、出生/継承、3D、公開デプロイは行っていない。Planner境界とMockのみ。
- 大規模性能とブラウザfps/入力応答p95は未計測。M6のworld-30000ベンチ指定は未対応として明示的に失敗する。

## 再開手順

1. DESIGN/DECISIONS/本ファイルを読み、`npm ci`、`npm run typecheck`、`npm test`。
2. `npm run dev` で遊び、`artifacts/sample-day3.json` / `sample-war-day4.json` をJSON入力から読み込む。
3. 人間試遊は `docs/PLAYTEST.md` を使用して実施し、実際の結果を記入。
4. [E1契約](ECONOMY_E1_CONTRACT.md)の実装差分を読み、`npm run economy:e1 -- baseline`と三つの対照ケースを実行する。次にE2の4世帯/事業の賃金・仕入・資金循環を数表で確定し、同じ人物Taskと実在庫で検証する。
5. 動機・行動の共通化は [v2インターフェース](AGENT_INTERFACES_v2.md) の認識・動機・判断の対照例と受入テストを準備し、経済Taskにも同じ境界を適用する。各段で既存90日ゲームの受入条件を保つ。
6. E2→E3で個別雇用主の所得循環と木材/装備・公職/軍を接続する。人間試遊の未完了を別に追跡し、結果を踏まえてM4を検討する。
