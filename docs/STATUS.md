# 現在の実装と未達

更新: 2026-10-03。現行は5人自律生活v24。採集・穀物売却後の食品取得・現金購入を共同比較する。次は[NEXT_SESSION](NEXT_SESSION.md)、条件は[DECISIONS](DECISIONS.md)、実測は[v24の結果](baseline/FOOD_ACQUISITION_V24_RESULT.md)。

## 実装されていること

- 40×24セル、1280×768の描画、障害物を迂回する移動、現地の採集・所有農夫の農作業、生育・収穫減少・再生待ち、動物の局所的な移動・成長。
- 穀物の分割運搬、畑・家・市場の本人所有の保管、Sの市場製パン、現物の原料・食品売買。物品・貨幣・所有・容量を保存し、穀物の直接食事を禁止する。
- 食事の2時間後の吸収、栄養帳簿、独立した活動疲労、荷重、睡眠履歴・入眠・自然起床、寒さ。v24で身体・生育・供給・睡眠の係数を変更していない。
- 本人の観察・記憶・感覚から採集／自己保管食品／売却後の購入／現金購入／未確認の探索を比較する。取得・摂食・吸収時刻、負担、成立見込み、期限、未成立時の代替と帰路を記録し、食品が少ない場合も売却候補を生成する。
- 到着後に現物・競合・提示を再確認する。売却成功と食品購入、買い手不成立と食品提示不在、疲労／避難の中断を区別し、対応する本人の結果から見込みを更新する。採集先の枯渇で市場再試行を抑止しない。
- 内部の体力0で死亡し、身体・位置・時刻を固定して判断・作業・睡眠・販売を止める。所有物は残り、生存者・生態・腐敗は続く。v23の死亡条件を維持する。
- 初期条件・観察・刺激・主観記憶・判断・外部指示・全Eventの保存、再実行、保存再開、判断再計算。画面で候補・除外理由・吸収見込み・実結果・死亡・所有品を確認できる。
- 人物パネルは身体ステータスの次に携帯中の所持品と運搬負荷を表示する。身体・栄養・睡眠・経験の小数値は小数点以下1桁を固定し、整数の時も末尾の0を表示する。所持金・個数・負担の整数パーセント表示は維持する。
